### 1.3 Strapping 引脚（上电瞬间必须为确定电平）

ESP32-S3 的 strapping 脚为 **GPIO0 / GPIO3 / GPIO45 / GPIO46**。本设计用到其中 3 个：

| 脚 | 本设计用途 | 复位窗口要求 | 处理 | 风险 |
|---|---|---|---|---|
| **GPIO0** | BOOT 按键 | 必须为**高**（否则进下载模式） | 外置 **10kΩ 上拉到 +3V3** + 按键到 GND | 低 |
| **GPIO3** | `TOUCH_IRQ` | 必须为**确定电平**（该脚 strapping 功能为 JTAG 信号源选择） | XPT2046 的 PENIRQ 为开漏低有效，**必须加 10kΩ 上拉**（该上拉同时满足 strapping 需求） | 中：需按 ESP32-S3 数据手册 Strapping 表核对该脚默认电平与上拉方向是否冲突；**冲突则按 §5-4 挪脚** |
| **GPIO45** | **未使用** | 该脚为 VDD_SPI 电压选择（内部默认下拉） | **保持悬空，严禁加上拉**；PCB 上留 1 个测试点即可 | 低 |
| **GPIO46** | `TOUCH_CS` | 必须为**确定电平**（ROM 信息打印/启动模式相关） | CS 上电必须为**高**（不选中）；加 10kΩ 上拉。**需核对该脚 strapping 默认电平是否为下拉** | 中：若默认下拉，则上拉与 strapping 冲突 → 按 §5-4 挪脚 |
| **EN** | 复位 | 上电必须为高 | 10kΩ 上拉 + 100nF 到地（τ = 10k×100n = **1ms**），复位按键到 GND | 低 |

> 引脚级结论以 **ESP32-S3 数据手册第 3.4 节 Strapping 表**为最终依据（本文件不臆测默认电平方向）。凡标注「需核对」的两项，画图前必须先查表。

## §3 关键电路参数（已修正版，每条给算式）

### 3.1 RS-485 失效安全偏置：680Ω 上拉 / 680Ω 下拉

**原设计问题**：论文 `:95` 用 15KΩ。含 120Ω 终端时 V_AB ≈ 13mV，仅为接收器门限（≥200mV）的 6.5%，总线空闲时输出电平不确定。

**修正算式（本设计取值 R_up = R_dn = 680Ω，V_CC = 3.3V）**

```
偏置回路总阻 = R_up + R_term + R_dn = 680 + 120 + 680 = 1480 Ω
偏置电流     = 3.3V / 1480Ω                = 2.23 mA
V_AB         = I × R_term = 2.23mA × 120Ω  = 0.2676 V ≈ 267 mV
```

等价闭式：`V_AB = 3.3 × 120 / (680 + 120 + 680) = 396 / 1480 = 267 mV` ✅

**裕量**：267mV / 200mV = **1.34 → 33% 裕量**，满足失效安全。

**必须注意：终端电阻数量会改变 V_AB**（本机是诊断工具，可能插在总线中段，也可能在末端）：

| 总线终端配置 | 等效 R_term | 偏置回路总阻 | I_bias | V_AB | 是否 ≥200mV |
|---|---|---|---|---|---|
| 仅本机 120Ω（推荐默认） | 120Ω | 680+120+680 = 1480Ω | 2.23mA | **267mV** | ✅ 裕量 33% |
| 两端各 120Ω（并联 60Ω） | 60Ω | 680+60+680 = 1420Ω | 2.32mA | **139mV** | ❌ **不满足** |
| 仅本机 120Ω + 偏置改 390Ω | 120Ω | 390+120+390 = 900Ω | 3.67mA | **440mV** | ✅ 裕量 120% |
| 两端各 120Ω + 偏置改 390Ω | 60Ω | 390+60+390 = 840Ω | 3.93mA | **236mV** | ✅ 裕量 18% |

**结论**：
- 本机**默认只焊 120Ω 终端、偏置用 680Ω**（V_AB=267mV）。
- 若现场发现两端都有终端（V_AB 掉到 139mV），把偏置换成 **390Ω**（V_AB 回到 236mV）。
- 680Ω 方案偏置电阻功耗：`P = I²R = (2.23mA)² × 680Ω = 3.38mW`（每只），0402 封装足够。
- **终端电阻默认不贴**（JP1 断开），仅在设备处于总线物理末端时由跳线接入。

### 3.2 120Ω 终端电阻（可跳线/焊接选择）

- 取值 **120Ω**（TIA/EIA-485-A 标准双绞线特性阻抗），封装建议 **0805/1206**（论文未指定功率，按最坏情况算）：
  `P = V_AB²/R = (0.267V)² / 120Ω = 0.59mW` → 0402 也够，但为方便手工跳线焊接选 0805。
- 接入方式：**JP1（2.54mm 跳线帽）或 0Ω 电阻，二选一**，与 120Ω 串联后再跨接 A/B。
- 默认状态：**断开/不贴**（诊断工具多数场合插在总线中段，不应引入第三个终端）。

### 3.4 ADC 输入分压：R1 = 30KΩ / R2 = 10KΩ（1/4 衰减）

**原设计问题**：论文 `:123` 用 R1=R2=10KΩ（1/2 衰减），最大可测 6.2V。但 RS-485 A 线共模范围 −7V~+12V，1/2 分压后为 −3.5V~+6V，远超 ADC 0~3.1V，BAT54S 会**长期钳位**导致波形削顶（缺口报告 B7）。

**修正算式**

```
衰减比      = R2 / (R1 + R2) = 10K / (30K + 10K) = 0.25 = 1/4
满量程输入  = ADC 满量程 × 4 = 3.1V × 4 = 12.4V
源阻抗      = R1 ∥ R2 = 30K × 10K / 40K = 7.5 KΩ
```

| 输入电压 | ADC 脚电压 | 是否被 BAT54S 钳位 |
|---|---|---|
| 3.1V | 0.775V | 否 |
| 12.4V | 3.100V | 否（钳位起点 3.3+0.3 = 3.6V） |
| 15V | 3.75V | 是（多余电流经 R1 泄放：I=(15−3.6)/30K=380µA） |

**BAT54S 正确接法**（BAT54S 是**串联对**，3 脚为公共中点）：
```
引脚1（阳极）→ GND
引脚3（中点）→ ADC_WAVE（信号）
引脚2（阴极）→ +3V3A
```
这样：信号 < −0.3V 时 D1 导通钳到地；信号 > +3.6V 时 D2 导通钳到 3.3V 轨。**接错成共阳/共阴封装则钳位失效。**

**RC 抗混叠**：R3 = 1KΩ，C24 = 10nF
```
fc = 1 / (2π × R3 × C) = 1 / (2π × 1000 × 10n) = 15 915 Hz ≈ 15.9 kHz
50kHz（100kSPS 的 Nyquist）处衰减 = 1/√(1+(50/15.9)²) = 0.303 → −10.4 dB
```

**适用边界（必须写进论文）**：本前端**仅适用于被测信号共模正常（0 ~ +12.4V 对 GND）的低压测试场景**。若要直接观测真实 RS-485 A/B 线的差分波形（共模 −7V~+12V），必须改用差分/隔离放大器（如 AMC1200、AMC1311 等，型号待定）或 AC 耦合后偏置到 1.55V 中点。**不能把 30KΩ 分压直接接到 A/B 线上**（共模负半周会经 BAT54S 灌入地，且分压网络会加载总线）。

**精度注意**：源阻抗 7.5KΩ 对 ESP32-S3 ADC 偏大，可能造成采样误差。两个可选缓解：
- (a) 保留运放缓冲，但**必须换轨到轨型号**（LM358 在 3.3V 单电源下输入共模上限约 1.8V、输出摆幅上限约 1.8V，**无法通过 0~3.1V 信号，属错误选型**，见 §5-7）；
- (b) 降低分压阻值到 **R1=12KΩ / R2=4KΩ**（源阻抗 3KΩ，满量程仍为 12.4V，代价是静态电流升到 12.4V/16K = 775µA）。

无论选哪种，**必须用 ESP-IDF 的 ADC 校准 API 实测标定**后再回填论文曲线。

### 3.5 Type-C 受电：CC1/CC2 各 5.1kΩ 下拉到 GND（必需）

- 依据：Type-C 规范规定 Sink 端需在 CC1、CC2 各接 **5.1kΩ ±10% 下拉到 GND**（Rp 为源端，Rd 为受电端）。
- **缺此电阻的后果**：标准 Type-C 电源（含 PD 充电器、Type-C 转 A 线在部分场景）**不会输出电压**，板子完全不上电。
- 数量与封装：**2 只，0402**。
- 若改用 **6P 简易 Type-C 母座**（只有 1 个 CC 焊盘，另一 CC 用 5.1kΩ 电阻短接处理）：**至少 1 只 5.1kΩ 到 CC**，且两 CC 焊盘需合并；本设计推荐 **16P 全功能座**（同时走 USB 数据到 CH340），此时**必须 2 只**。

### 3.6 下载电路：改用 CH340C / CH340N（内置振荡器）

| 方案 | 是否需外部晶振 | 封装 | 有无 DTR/RTS | 结论 |
|---|---|---|---|---|
| **CH340C** | **不需要** | SOP-16 | **有**（可做自动下载） | ✅ **推荐**（要与原 CH340G 引脚兼容且需自动下载时选它） |
| **CH340N** | **不需要** | SOP-8 | 无（8 脚精简版，**不支持自动下载**，需核对 WCH 手册） | 面积最省，但只能手动按 BOOT+RESET 下载 |
| CH340G（论文原选） | **必需 12MHz 晶体 + 2×22pF** | SOP-16 | 有 | 论文 `:83` 未提晶振 → **照论文画板 CH340G 不工作**（缺口报告 B8） |

**CH340C/N 外围（3.3V 供电）**：
- `VCC = +3V3`；`V3` 脚接 **0.1µF 到 GND**（若数据手册要求 V3 接 VCC，则以手册为准 —— **待核对 WCH CH340C 数据手册对应版本**）。
- `TXD → UART0_RX (GPIO44)`；`RXD ← UART0_TX (GPIO43)`（**交叉连接**，不要接反）。
- `UD+ → USB_DP`；`UD− → USB_DM`（直连 Type-C 座，中间可串 0Ω 便于改线）。
- VCC 就近 100nF 去耦。

**若坚持 CH340G**：必须补 `Y1 = 12MHz 无源晶振 + C16/C17 = 22pF ×2`（论文未提及，属缺口）。

**自动下载（可选）**：`DTR`/`RTS` 经 **2×S8050 + 2×10kΩ** 交叉控制 `EN` 与 `GPIO0`（经典 ESP32 自动下载电路），实现免手动按键烧录。不加则每次下载需手动「按住 BOOT → 点 RESET → 松开 BOOT」。

### 3.8 背光：按「含 XPT2046 的 ILI9341 SPI 模组」口径

- 口径确定：BOM 选**含 XPT2046 的 ILI9341 SPI 模组**（与代码 4 线 SPI + 独立 CS 一致）。**模组自带背光升压/限流电路和 MOS 管**，只引出 VCC/GND/BL。
- 因此论文 `:105` 的「白光 LED 串联 + 100Ω 限流 + 2N7002」**属裸屏口径，与模组口径矛盾**（缺口报告 B3/B4）。
- **本设计做法**：`GPIO7 → R12(10kΩ 下拉) → Q3(2N7002 栅极)`，Q3 源极接 GND，漏极接模组 `BL` 脚 —— 低边开关，**低电平点亮、上电默认关断**。
  - 10kΩ 下拉的作用：GPIO7 上电为高阻，无下拉会导致背光随机瞬亮。
  - 若模组 BL 脚为高有效且电流 < 12mA，可**直接由 GPIO7 驱动**（省掉 Q3），但需先实测模组 BL 电流。
- 论文 `:105` 的 100Ω 限流电阻：**在模组口径下不需要**（模组已自带限流），保留位号 R13 作**选贴**，仅裸屏方案才装。
- **PWM 调光**：代码全工程 `ledc` 零命中，**当前无 PWM 实现**；若要调光需在代码侧改用 LEDC，硬件侧 Q3 已具备条件（预留）。

### 3.9 TFT 上电时序（原理图注记 + 代码核对项）

论文 `:101`：先供 VCC/IOVCC → 延时 ≥10ms → 释放 RST → 延时 120ms → 发初始化序列。
- 原理图上把 `TFT_RST` 标注「上电默认拉低（模组内部下拉或加 10kΩ 下拉到 GND），由 GPIO8 控制释放」。
- **代码核对项**：`tft_driver.c` 的复位时序需与此 ≥10ms / 120ms 一致（属软件侧，本文件不改代码，仅提示核对）。

### 3.10 按键：内部上拉使能 + PCB 预留 10kΩ 外部上拉位 + 100nF 消抖（选贴）

**方案（解决缺口报告 A2 的论文自相矛盾）**

| 项 | 取值 | 算式/说明 |
|---|---|---|
| 代码侧 | `key_scan.c:68` `.pull_up_en = GPIO_PULLUP_ENABLE`（**保持不动**，本文件不改代码） | ESP32-S3 内部上拉典型 ≈ **45kΩ** |
| 硬件侧 | **PCB 预留 10kΩ 外部上拉焊盘（R15–R18，选贴）** + **100nF 消抖电容（C20–C23，选贴）** | 两者与内部上拉并联 |
| 只贴电容不贴上拉 | τ = 45kΩ × 100nF = **4.5 ms** | 与论文 `:115` 的 1ms **不符** |
| **贴上拉 + 电容（推荐）** | R_eff = 45k ∥ 10k = **8.18 kΩ**；τ = 8.18k × 100n = **0.82 ms** | ≈ 论文的 1ms（论文原算式 10k×100n = 1ms） |

**结论**：**要论文自洽，就必须贴外部 10kΩ**（τ≈0.82ms，与论文 1ms 同级）；只靠内部上拉则 τ≈4.5ms，论文算式不成立。
- 按键另一端接 GND，低有效；4 只按键均为独立 GPIO 直连，无矩阵。
- 软件消抖 30ms（`BTN_DEBOUNCE_MS`）、长按 800ms（`BTN_LONG_PRESS_MS`）与论文 `:415` 的「10ms 周期 / 1 秒长按」不一致，属论文需修订项。

### 3.11 状态 LED：GPIO48 预留

| 项 | 说明 |
|---|---|
| 本设计（自绘板） | `GPIO48 → R19(1KΩ) → LED2 → GND`。电流 = (3.3 − 2.0) / 1kΩ = **1.3mA**（低亮度指示足够）；要更亮改 470Ω（2.77mA） |
| ⚠️ 若用官方 **ESP32-S3-DevKitC-1 开发板**做原型 | 板上 **GPIO48 已接板载 WS2812 类 RGB LED**，需**单总线时序（RMT）驱动**，普通 `gpio_set_level` **点不亮**。此场景下要么改用 RMT 驱动，要么另选空闲 GPIO 接外置 LED |
| 代码状态 | `LED_PIN` 在 `app_config.h:44` 定义，**全工程零引用**（论文写了、代码未实现）→ 原理图保留该网络，标注「预留未实现」 |

### 3.12 电源：Type-C 5V → AMS1117-3.3

| 项 | 取值/算式 | 说明 |
|---|---|---|
| LDO | **AMS1117-3.3**，SOT-223 | 论文 `:59`；输入 4.5~12V，输出 3.3V/1A |
| 压差校核 | V_in − V_out = 5 − 3.3 = **1.7V** > 压差典型 **1.1V** ✅ | 有 0.6V 裕量（输出电流下降时压差更小） |

| 耗散 | `P = (5 − 3.3) × 0.352A = 1.7 × 0.352 = 0.598 W ≈ 0.6 W` | |
| 效率 | 3.3 / 5 = **66%**（其余 34% 变热） | |
| **铜箔散热要求（必须写进 PCB 规则）** | SOT-223 的 tab 焊盘**铺铜 ≥ 100mm²**，并打**过孔阵列（≥ 9 个 0.3mm 过孔）到内层 GND 平面**。按 θJA ≈ 60~100°C/W 估：ΔT = 0.6W × 60~100 = **36~60°C**，环境 25°C 时结温 61~85°C，低于 125°C 上限但**无铜箔会超温** | 论文 `:67` 只算电流裕量，未讨论热设计（缺口 C14） |
| 输入滤波 | **10µF 钽 + 100nF 陶瓷**（论文 `:65`） | |
| 输出滤波 | **22µF 钽（ESR 0.5Ω）+ 100nF 陶瓷**（论文 `:65`） | ⚠️ AMS1117 要求输出电容 ESR 落在 **0.1~10Ω**；若用纯 MLCC（ESR ≈ 5mΩ）**可能振荡**，必须串 **0.5Ω** 电阻或保留钽电容 |
| 输入保护 | **PTC 自恢复保险丝（F1）+ 输入 TVS（D1）** —— 论文未提，属缺口（C11） | PTC 按 I_hold ≈ 0.5~0.75A、V ≥ 6V 选型；TVS 建议 SMBJ5.0A（standoff 5V，V_C ≈ 9.2V，低于 AMS1117 的 15V 上限）。**具体料号待定** |
| 电源指示 | `+3V3 → R1(1KΩ) → LED1 → GND`，电流 = (3.3−2.0)/1k = 1.3mA | 论文未提，属缺口（C12） |
| 模拟电源分区 | 数字/模拟 3.3V 平面经**磁珠 100Ω@100MHz 单点连接**（论文 `:149`） | 原理图上标 `+3V3` → 磁珠 → `+3V3A` |

### 4.4 ERC 检查清单（预期会报什么 + 怎么处理）

| 预期告警 | 出现原因 | 处理 |
|---|---|---|
| 电源引脚未驱动（Power pin not driven） | 电源网络只有负载、没有源 | 在 P1 的 `+5V_VBUS` / `+3V3` / `+3V3A` 上各放一个**电源标志（PWR_FLAG）** |
| 引脚未连接（Pin not connected） | GPIO45 悬空、未用 GPIO、模组 NC 脚 | 对**确实悬空**的脚打 **NC 标记**（不是放个 no-connect 就完，要在符号属性里勾 NC） |
| 输入脚无驱动（Input pin not driven） | 按键脚靠内部上拉、`TOUCH_IRQ` 靠外部上拉 | 把对应脚在符号里改成 **Passive/双向** 属性，或确保外部上拉已画 |
| 输出冲突（Output pin conflict） | RS-485 的 A/B 是双向节点 | MAX3485E 的 A/B 脚属性设为 **Bidirectional/Passive** |
| 网络名重复/大小写不一致 | `RS485_A` 与 `RS485A`、`TFT_MOSI` 与 `TOUCH_MOSI` 混用 | 按 §2.2 规范**全局搜索替换**，确保一个信号只有一个名字 |
| 元件无封装（转 PCB 时） | 自建库元件未绑封装 | 逐个补：模组、Type-C、按键、端子、PTC、TVS |
| 晶振相关告警 | 若已删除 40MHz 晶振 | 删除 Y1/C16/C17 后告警自动消失；**若走 CH340G 路线则必须保留这三项** |
| 单端网络（只有 1 个连接点） | 网络标签打错字 | 逐个点开看，全部消除 |
| 未连接的模组散热焊盘 | ESP32-S3 模组中间 GND 焊盘 | 必须接地，不能 NC |

| **1** | **CH340G vs CH340C / CH340N** | **CH340C（SOP-16）** | 内置振荡器，省掉 12MHz 晶振 + 2×22pF（省 3 个料、省 0.5 元、省 PCB 面积）；与 CH340G **引脚兼容**，论文只需把 `:83` 的型号改一个字母。CH340N（SOP-8）更小但**无 DTR/RTS，不能自动下载** | 论文 `:83`、BOM 行 7/8/11 |
| **2** | **RS-485 差分线宽 0.2 vs 0.3mm** | **0.2mm 线宽 + 0.2mm 间距** | 论文 `:145` 写 0.2mm/0.2mm 且目标 100Ω 差分；KiCad 工程里 `RS485` 网络类是 0.3mm，属不一致（缺口 C8）。**但精确差分阻抗必须用厂家阻抗计算器按实际层叠核算**（嘉立创 4 层 1.6mm 常规层叠下 0.2/0.2mm 约在 100Ω 量级，**精确值待核算**） | 论文 `:145`、立创EDA 设计规则 |
| **3** | **触摸是否真做** | **硬件保留（选含 XPT2046 的模组），论文标注「预留未实现」** | 代码 `app_config.h:15-19` 定义了引脚但**零引用**，`input_event.c:3` 自述为占位符。硬件保留成本 ≈ 模组差价（约 10~20 元），且模组自带不用额外画电路；**若彻底不做可省这笔钱，但需删论文 4.4.3** | 论文 4.4.3、BOM 行 4/5/40 |
| **4** | **TOUCH_CS(46)/IRQ(3) 是否挪到非 strapping 脚** | **推荐挪到 GPIO14（CS）/ GPIO21（IRQ）** | 两脚都是 strapping 脚（缺口 B10），上电瞬间被外设拉偏会导致偶发启动失败/无法下载，且现场极难定位。**代价：需同步改 `app_config.h:17-18` 与论文 `:109`**（本轮不碰代码，等主人点头）。若不挪，必须实测上电波形确认电平与 strapping 默认值一致 | 代码 `app_config.h:17-18`、论文 `:109` |
| **5** | **是否加 DTR/RTS 自动下载电路** | **加（2×S8050 + 2×10kΩ）** | 不加则每次烧录都要「按住 BOOT → 点 RESET → 松手」，调试期极其痛苦；成本 < 0.3 元 | BOM 新增行 50/51、P3 页 |
| **6** | **状态 LED 是否做** | **做（普通 LED + 1kΩ，1.3mA）** | 代码补 1~3 行即可点亮；注意**若用官方 DevKitC-1 开发板，GPIO48 是板载 WS2812，普通 GPIO 电平点不亮**（需 RMT 驱动）。自绘板无此问题 | 论文 `:34-35`、代码 `app_config.h:44`、BOM 行 41/43 |
| **7** | **ADC 前端是否保留 LM358** | **删除（或换轨到轨运放）** | LM358 在 3.3V 单电源下输入共模上限约 1.8V、输出摆幅上限约 1.8V，**根本过不了 0~3.1V 信号**，属错误选型。删除后靠 7.5KΩ 源阻抗 + ADC 校准实测；若要缓冲，换 MCP6001 / GS8551 / OPA333 一类轨到轨型号（**具体料号待定**） | 论文 `:125`、BOM 行 33 |

| 待定项 | 缺什么信息 |
|---|---|
| ESP32-S3-WROOM-1 的 IPEX 变体料号（若需外置天线） | 主人是否要外置天线；N8R8 默认 PCB 天线 |
