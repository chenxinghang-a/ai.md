### 2. 新增 `_switch_backend()` 方法

```python
def _switch_backend(self, backend: str = ""):
    """多后端模式下临时切换LLM到指定后端，返回旧llm以便恢复"""
    if not self._multi_mode or not backend or backend not in self.backends:
        return None
    old_llm = self.llm
    profile = self.backends[backend]
    from ..backends.client import LLMClient
    self.llm = LLMClient(
        base_url=profile.base_url,
        api_key=profile.api_key,
        model=profile.model or "",
        proxy=profile.proxy or self._proxy,
    )
    # 给所有agent换llm
    for agent in self.agents.values():
        agent.llm = self.llm
    return old_llm
```

**作用**: 多后端模式下，根据 `backend` 名称创建对应的 LLMClient 并临时替换到所有 agent。

---

### 3. 新增 `_restore_llm()` 方法

```python
def _restore_llm(self, old_llm):
    """恢复原来的llm"""
    if old_llm is None:
        return
    self.llm = old_llm
    for agent in self.agents.values():
        agent.llm = old_llm
```

**作用**: 调用结束后恢复原来的 LLM，保证后续调用不受影响。

### 4. `chat()` 方法 — 新增 `backend` 参数 + 解耦内部逻辑

**原签名**:
```python
def chat(self, user_input: str, mode: str = "auto",
         return_details: bool = False, auto_save: bool = True, **kwargs):
```

**新签名**:
```python
def chat(self, user_input: str, mode: str = "auto",
         return_details: bool = False, auto_save: bool = True,
         backend: str = "", **kwargs):
```

**原逻辑**（所有代码在 `chat()` 方法体内）:
```python
def chat(self, ...):
    # arena特殊路径
    # 智能路由 + classifier
    # 简单问题快速路径
    # 复杂任务
    # auto模式: V5
```

**新逻辑**（`chat()` 只做backend切换，内部逻辑移到 `_chat_internal()`）:
```python
def chat(self, ...):
    # 多后端模式下切换llm（若指定backend）
    old_llm = self._switch_backend(backend)
    try:
        return self._chat_internal(user_input, mode, return_details, auto_save, output_dir, **kwargs)
    finally:
        self._restore_llm(old_llm)
```

**作用**: 
- `backend=""`（默认）→ 和以前完全一样，走默认后端
- `backend="deepseek"` → 切换到指定后端再执行
- 用 `try/finally` 保证无论成功失败都能恢复原来的 llm
