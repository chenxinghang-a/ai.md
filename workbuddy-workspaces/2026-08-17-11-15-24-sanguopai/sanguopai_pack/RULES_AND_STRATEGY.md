# 三国牌 · 规则与打法基准（锁定版）

> 本文件是**唯一权威**：规则以此为准，代码与它不一致就是 bug。结算核心已通过双实现交叉验证  
> （`env/game.py` 的 `step()` 与 `env/card_counter.py` 的 `resolve_settle()`，240 局实测零差异）。

---

## 一、核心循环（4 轮闭环）

```
看公共牌 → 决定这轮出牌（140 选 1：阵营 + 手牌子集）
        → 结算（赢家收豆 / 输家付豆）
        → 看对手出牌与结果 → 决定下一轮
```

牌**循环使用**：本轮用掉的手牌 + 被用过的阵营公共牌回库洗混，再补到手牌 8 张、公共牌固定张数。所以"留牌"是跨轮的核心技巧。

---

## 二、规则

| 项    | 规则                                                                            |
| ---- | ----------------------------------------------------------------------------- |
| 人数   | 5 人各自为战                                                                       |
| 牌    | 52 张，`code = 花色×13 + 点数`（点数 0=2 … 12=A）；**A 可当 1 或最大，2 最小**                   |
| 手牌   | 每人 8 张；4 轮，一副牌贯穿不重置                                                           |
| 公共牌  | 魏 3 张 ｜ 蜀 0 张 ｜ 吴 2 张（公开、公用，每轮补回固定张数）                                         |
| 每轮动作 | **同时**出牌，140 个动作：**魏**=出2张手牌+3张魏公共 ｜ **蜀**=出5张手牌 ｜ **吴**=出3张手牌+2张吴公共（都是凑 5 张） |
| 牌型倍率 | 单张10 对子20 两对30 三张40 顺子60 同花80 三带二100 四炸400 同花顺1000                            |
| 名次   | 按牌型大小排；同分并列同名次；多个第一名时后续名次顺延                                                   |
| 牌型比较 | 标准德州（先比等级，再比 tiebreak）；**A2345 记 5 高**，A 也能做最大顺子顶                             |
| 底分   | 4500 ｜ 入场/补豆 16 万 ｜ 门票 0                                                      |

## 三、结算（**两侧不对称，最容易错的地方**）

**每个输家对每个第一名各付一份**（并列第一就各付一份；单轮总输可以超过 1800 万，**不额外卡**）：

```
L    = 赢家牌型倍率 × 暴击 × 输家名次倍率 × 杀牌 × 4500
实付 = min( L , 1800万 , 赢家收款上限 , 输家当前豆 )
```

| 因子   | 取值                                                     | 取谁的量       |
| ---- | ------------------------------------------------------ | ---------- |
| 牌型倍率 | 上表                                                     | **赢家**的牌型  |
| 暴击   | 输家与赢家**同阵营** → 赢家阵营人数(含赢家) 查 `1,2,4,8,12`；**不同阵营 = 1** | **赢家**阵营   |
| 名次倍率 | ②32 ③24 ④12 ⑤4                                         | **输家**的名次  |
| 杀牌   | 与赢家**同类**人数(含赢家) 查 `1,2,4,8,16`                        | **赢家**的牌型类 |
| 杀牌分类 | **单张/对子/两对/三张 = 同一类**；顺子、同花、三带二、四炸、同花顺各自一类             |            |

**两侧封顶不对称**（⚠️ 反复搞错过）：

- **输（封顶）**：恒 **1800 万**，看**输家当前豆**——"管你有多少"，付不满即破产，**缺口赢家自己吃亏**（不为负、不欠债）。
- **赢（收款上限）**：`clamp( max(赢家入场豆, 赢家当前豆), 450万, 1800万 )` —— 带≥1800万收满；450万~1800万取入场/当前较大者；带<450万每份**只收 450万**（低豆赢不大）。

## 四、打法（从公式直接推出来，不是猜的）

### 输家自己可控的三要素 → 最大摆动 1536 倍

| 可控项          | 最便宜    | 最贵       | 倍差  |
| ------------ | ------ | -------- | --- |
| 名次           | ⑤=4    | ②=32     | 8×  |
| 暴击（是否与赢家同阵营） | 异阵营=1  | 同阵营5人=12 | 12× |
| 杀牌（同类拥挤度）    | 独自一类=1 | 同类5人=16  | 16× |

**8 × 12 × 16 = 1536 倍**。三个都能自己选：名次靠出牌强弱，暴击靠选阵营，同类靠选牌型。

> ⚠️ 本节是从**结算公式**推出的"静态结构"，用来**理解**这个游戏；**真正的策略交给训练自己学**（DMC 就是干这个的）。别把这里的静态结论直接当决策规则用——牌桌上的权衡是动态的。

### 铁律一：**赢不了就主动垫⑤**

同一局面下（赢家顺子/异阵营/同类=1）：⑤付 108 万、③付 648 万、②付 864 万。  
**③ 比 ⑤ 贵 6 倍、② 贵 8 倍**。名次②③④是死亡区，垫⑤永远不亏。

### 事实二：**小牌型赢家的"单份收豆"反而更高**（反直觉）

推导：**赢家是"三张及以下"⇒ 其余人的牌型也只能落在小牌类 ⇒ 同类恒为 5 ⇒ 杀牌 = 16 倍。**  
所以小牌赢家的真实收益 = 牌型倍率 × 16：

| 赢家牌型 | 单张      | 对子      | 两对      | 三张      | 四炸  | 三带二 | 同花 | 顺子 | 同花顺  |
| ---- | ------- | ------- | ------- | ------- | --- | --- | -- | -- | ---- |
| 有效收益 | **160** | **320** | **480** | **640** | 400 | 100 | 80 | 60 | 1000 |

→ 三张(640) > 两对(480) > 四炸(400) > 对子(320) > 三带二(100) > 同花(80) > 顺子(60)。  
**注意这只是"单份收豆"的口径**。你**不打**手里成型的顺子/同花，等于把这一轮的豆让给别人（而且照样可能被电），所以"打不打"是**动态权衡**，不是"打出去 = 自废收益"这么简单。真正的最优解必须考虑 4 轮的跨轮收益，**交给训练学出来**。

### 铁律三：同类拥挤是博弈

大家都往小牌类躲 → 同类=5 → **16 倍** → 集体被电。所以要么**赌别人不敢全躲**（自己在小类里当赢家吃 16 倍），要么**成型大牌就走人把赢家拉出小类**（kill→1，代价是自己也拿不到暴击）。

### 留牌判据（跨轮）

1. 本轮先算「能不能凑到顺子以上」——能 → 全力争①；
2. 不能 → 本轮定位⑤，出**最廉价**组合（别浪费好牌）；
3. 必留：连张 / 同花张 / 对子 / 三条（顺子·同花·四炸素材）；优先弃：异花断连的孤张、纯踢脚大牌；
4. 第 4 轮没有下一轮 → 直接打最强；
5. 牌会回库重抽，所以"省牌"价值低、"本轮能不能赢"价值高。

### 常见错直觉

| 错的          | 对的原因                                                  |
| ----------- | ----------------------------------------------------- |
| 牌越大越好       | 赢家收益 = 牌型 × 类拥挤；三张(640) > 四炸(400)                     |
| 点数越大越好      | 只看 5 张组合；孤张 A 只是踢脚，连张/同花张才值钱                          |
| 输了就是被别人大牌压  | 小牌赢家的杀牌 16 倍更贵：单张赢家 + ② = 10×16×32×4500 = 2304 万 → 封顶 |
| 赢家必收 1800 万 | 每份还受赢家自己的收款上限：16 万入场的小豆赢家每份只收 450 万                   |
| 同阵营人多好      | 只抬高你输给同阵营时的暴击(≤12×)，还跟同阵营抢公共牌                         |
| 垫⑤没面子       | ③多付 6 倍、②多 8 倍，垫⑤是公式里最便宜的动作                           |

## 五、观测与训练目标（与代码对应）

**训练目标一句话**：4 轮里让最终落袋的豆最多。奖励 = **净豆（无任何塑形）**，回报 = γ=1 的 MC return-to-go
`sign(Δ)·log1p(|Δ|/1e5) / log1p(4×cap/1e5)` —— 有符号对数压缩到 `[-1,+1]`：保序（同一决策内 argmax 不变），
但让"穷座位输光(−0.036×cap)"与"富座位赢满(+4×cap)"的梯度同量级（直接除以 scale 会差 ~100 倍）。

状态 **706** 维 = 基础 **194** + 历史块 **512**：

| 基础段                                  | 维度           |
| ----------------------------------- | ------------ |
| 我的手牌 / 公共牌 / 出现过的牌                   | 52 + 52 + 52 |
| 轮次                                  | 4            |
| 我的豆 + **我的财富档（2 档）**                 | 2 + 2        |
| **破产距离**（还能吃几份自己的封顶）+ 本局盈亏/入场豆       | 1 + 1        |
| 各阵营我能凑的最强牌型                         | 3            |
| 对手豆 + 对手入场豆                         | 4 + 4        |
| **对手收款档**（3 档 × 4 人）                 | 12           |
| **我 vs 对手最大 / 平均**（log 比）           | 2            |
| **对手里穷人的比例**                          | 1            |
| 存活数 + 牌库                            | 1 + 1        |

| 历史块（每轮 × 每个对手 = 32）           | 维度 |
| ----------------------------- | -- |
| 他出了哪个阵营                       | 3  |
| **他这轮从手牌里花掉的那几张（点数计数，不含公共牌）** | 13 |
| 他的牌型                          | 9  |
| **他的名次**                      | 5  |
| **他被结算了多少（符号+对数）**            | 1  |
| **他是否破产**                     | 1  |

> 注意：**不要**用"他打出的 5 张牌的点数大小"读牌——牌型是「手牌+公共牌」的组合产物，人家手里两张小的、公共牌刚好补个葫芦，看着就"大"了。有信息量的只有「他愿意花掉手里哪几张」+「结果如何」。

动作 45 维 = 阵营(3) + 用了哪几张手牌(8) + 5 张点数计数(13) + 花色计数(4) + 牌型(9) + 杀牌类(6) + 牌型倍率(1) + tiebreak(1)。

### ★ 豆量决定策略 → **分 2 档 head 的 Q 网络**（本版核心）

豆子数量不是"一个特征"，它**改变了整条 payoff 曲线的形状**。写清两侧上限：

```
U(M) = clamp( max(入场豆, 当前豆), 450万, 1800万 )   每份最多"收"多少
D(M) = min( 1800万, M )                            每份最多"输"多少
```

| 档 | 范围 | U/D | 结构 | 最优策略 |
|---|---|---|---|---|
| **0 高杠杆** | M ≤ 450万 | 450万 / M ∈ **[1, 28]** | U 是常数、D 随 M 线性 → **越穷越像免费彩票**：16万 的人输光只亏 16万，赢一把每份收 450万、4 家 1800万（**112 倍杠杆**） | **激进**：放开追赢，反正输光有补豆兜底 |
| **1 对称** | M > 450万 | **1 : 1** | U = D = min(M, 1800万) → 完全对称，还叠加名次②③④(32/24/12)+暴击12×+杀牌16× | **保守**：赢不了就垫⑤、避同阵营、避同类扎堆 |

所以网络是 **共享 trunk + 2 个 head**，按自己的财富档选 head（`train_dmc.py: QNet/tier_of`，`game.html: qAllHeads/tierOf`）。
一张网络同时拟合这两种目标只会折衷成"谁都不最优"的平均策略——这不是调参能解决的。

> **为什么是 2 档而不是 3 档**：450万 以上"M 具体多少"只改绝对尺度、不改结构。若在 1800万 再切一刀，
> 中间档在真实持久池里只占 **3.2%**（实测：穷 77.6% / 中 3.2% / 富 19.2%，因为穷档赢一次就直接跳到封顶），
> 样本太少训不动。切在**结构拐点**（450万）而不是**封顶**（1800万）才是对的。
> 注意"对手收款档"仍保留 3 档 —— 那是"我能从他那收多少"的信息，越细越好，与 head 数无关。

### ★★ 咸鱼陷阱：为什么穷人在这个规则里**翻不了身**（老板的直觉，已用引擎证实）

单份实付 = `min( L, 1800万, 赢家收款上限, 输家当前豆 )`。把这句话拆开看**两侧的天花板由谁决定**：

| 方向 | 天花板由谁决定 | 后果 |
|---|---|---|
| **赢** | `min(赢家收款上限, **输家的钱包**)` | **桌上没钱 → 你赢了也收不到钱** |
| **输** | `min(1800万, **你自己的钱包**)` | 攒起来的钱全部暴露成风险敞口 |

**实测账本**（我赢一局葫芦、4 家都垫第⑤名；数字来自真实引擎 `resolve_settle`）：

| 场景 | 我一局净收 | 被谁卡住 |
|---|---|---|
| 我 16万 赢 · 4 家都 16万 | **64万** | 输家当前豆（16万/份） |
| 我 900万 赢 · 4 家都 16万 | **64万** | 输家当前豆 ← **钱多了，赢的一分没多** |
| 我 1亿 赢 · 4 家都 16万 | **64万** | 输家当前豆 |
| **我 2亿 赢 · 4 家都 16万** | **64万** | 输家当前豆 ← **2亿 也没用** |
| 我 16万 赢 · 4 家都 1亿 | 1800万 | 赢家收款上限（450万/份） |
| 我 1亿 赢 · 4 家都 1亿 | 7200万 | 封顶 1800万 |

→ **三条铁律**：
1. **赢的天花板由别人（输家的钱包）决定，输的天花板由自己决定。** 所以在咸鱼桌上，带 16万 和带 2亿 赢的钱**完全一样（64万）**——你手里的钱对"赢"没有任何帮助。
2. **攒钱只会把自己变成提款机**：手上的钱越多，输的时候一份就输得越多（`min(1800万, 你的豆)`，没有财富折扣）。16万 的咸鱼输光只亏 16万；攒到 900万 的人一局就能吐掉 900万。
3. **"一开始给多点"（初始豆 1亿→2亿→10亿）救不了咸鱼，只扩大"富人圈"**。实测（400 局、取后 100 局快照）：

| 初始区间 | 中位数 | <50万 占比 | 450~1800万 占比 | ≥1800万 占比 | 破产/局 |
|---|---|---|---|---|---|
| 16万~1亿 | **16万** | 77.7% | 2.2% | 13.4% | 3.66 |
| **16万~2亿（现默认）** | **16万** | 65.6% | 1.1% | **31.6%** | 3.30 |
| 16万~10亿 | **16万** | 56.6% | 0.8% | 40.6% | 2.72 |

**中位数三组恒为 16万（补豆地板）**，而 `450万~1800万` 中间层只有 **0.8~2.2%** —— 池子是**双稳态**的：
要么在底部 16万、要么在顶部 ≥1800万，**中间阶层不存在**。因为跳出底部只有两条路：连续赢好几局（每局仅 +64万，同时每局都有归零风险）或被匹配到富桌赢一次（+1800万 直接跳顶）。
> 这同时反向验证了"分 2 档 head"是对的：真正的结构拐点只有 450万 一处（中间层不存在）。

**对训练的启示**：`--starting_hi` 不是无关紧要的初值，它决定训练时遇到的财富分布（1亿 是"77.7% 咸鱼 + 13.4% 富人"，2亿 是"65.6% + 31.6%"）。**2亿 让对称档的样本翻倍**，富档 head 才训得动。

### ★★★ EV 恒等式：「低豆高 EV」成立的条件是**桌上比你富**——本质是"劫富"，不是"低豆"

把单局 EV 写出来（5 人局 P(第一)≈20%；赢 = 4 家各付一份，输 = 自己付一份）：

```
EV = 0.2 × 4 × min(我的收款上限, 对手豆)  −  0.8 × min(1800万, 我的豆)
      └──────── 赢的期望 ────────┘         └──── 输的期望 ────┘
```

| 我 / 对手 | 赢 | 输 | **单局 EV** |
|---|---|---|---|
| 16万 / 16万（同富） | +64万 | −16万 | **0** |
| 900万 / 900万（同富） | +3600万 | −900万 | **0** |
| 1亿 / 1亿（同富） | +7200万 | −1800万 | **0** |
| **16万 / 1亿（我穷他富）** | +1800万 | −16万 | **+347万** |
| 1亿 / 16万（我富他穷） | +64万 | −1800万 | **−1428万** |

> **同富桌上，EV 恒等于 0 —— 无论 16万、900万还是 1亿。** 因为 `4 × 20% = 80%`，赢的份数期望刚好等于"不是第一"的概率，而赢/输的上限口径又相同（同富时 U=D）。
> 这不是巧合，是**设计出来的零和**：桌内谁也别想赢谁的钱。

**所以"低豆高 EV"的真正变量不是"低豆"，而是"相对贫穷"**：
- 你比同桌穷 → **+347万/局**（被富人补贴）；
- 你比同桌富 → **−1428万/局**（在补贴全桌）；
- 一样富 → **0**。

**实测（把"我"放进不同桌子跑 400 局、豆持久、破产补 16 万）**：

| 我 / 桌子 | 平均每局 | **终局豆** | 破产 |
|---|---|---|---|
| 16万 · 全咸鱼桌 | −12万 | 280万 | 324 |
| **1亿 · 全咸鱼桌** | −36万 | **276万** | 312 |
| **10亿 · 全咸鱼桌** | −255万 | **260万** | 155 |
| **16万 · 全富桌** | +16万 | **9931万** | 217 |

→ **1亿、10亿 坐上咸鱼桌都会被打回 ~270万**；16万 坐上富桌能滚到近 1亿。

**这就把「低豆高 EV」和「咸鱼不能翻身」接成了一件事**：
1. 低豆 EV 高是真的（被富人补贴）——**但前提是桌上有富人**；
2. 而**只要你爬上去，你就立刻变成补贴者**（因为 73% 的桌子是咸鱼桌，你必然频繁坐上）→ 富不持久；
3. 于是均衡点被压在**补豆地板**：那里你既是受益人（偶尔抽到富桌）又是受害者（多数时候抽到咸鱼桌）。

**结论：这不是"低豆占便宜"，而是「财富强制再分配」** —— 谁富起来，系统就把钱抽回去补贴咸鱼，直到所有人挤在地板上。玩家体感 = "赢一点 → 被拉去咸鱼桌慢慢还 → 只能充钱"。和「赢家吃亏」「450万地板」「补豆 16万=¥10」一起，构成完整的抽水循环。

### ★★★ 场次门槛：为什么真实牌桌上没那么多咸鱼（老板体感纠正，2026-09-14）

我前述模型里有 **3 个假设是我自己填的、不是游戏规则**，必须标出来：
1. **破产固定补 16万**（不是"随机 16~160万"）；
2. **没有入场门槛**（25 人同场随机抽）；
3. **破产者永远留在同一张桌**。

老板反馈"我打匹配没感觉有这么多咸鱼"——**他的体感是对的**。四种机制对照（400 局、取后 100 局快照、同为贪心策略）：

| 机制 | 中位数 | <50万 占比 | 450~1800万 | ≥1800万 占比 | 破产/局 |
|---|---|---|---|---|---|
| 无门槛 + 破产补 **16万**（我原模型） | 16万 | **65.9%** | 1.8% | 29.8% | 3.25 |
| 无门槛 + 破产补 **16~160万**（老板建议） | 100万 | **31.8%** | 1.8% | 37.0% | 3.10 |
| **门槛 1800万 + 破产才离场补位** | 33057万 | **0%** | 0.6% | 99.4% | 0.26 |
| **门槛 1800万 + 出手后不够门槛就换场** | 35597万 | **0%** | 0.0% | 100.0% | 0.22 |

**两个结论**：
1. **"补 16~160万"方向对、但只解决一半**：咸鱼占比 65.9% → **31.8%（腰斩）**，中位数 16万 → 100万。因为它只是把地板抬高，没改变"破产者留在同一桌"这个结构。
2. **决定性因素是门槛**：一旦设了入场门槛，咸鱼**直接归零**，池子里 99.4% 都是 ≥1800万 —— 这才是真实牌桌的样子。所以**训练环境得按你要模拟的场设门槛**。

**顺带更正一个充值动机的推断**：门槛场里破产率只有 0.26 人次/局（无门槛场 3.25）—— 所以门槛场里的充值**不是"防破产"，而是"防降级"**：掉到门槛以下就被赶去低场，玩家为了回到高场才充钱。跟"破产补 16万"是两套机制。

对应新增训练参数：

```bash
# 无门槛（全服视角）：破产补豆改成区间，不再全员恒定 16万
python -m sanguopai.train_dmc --games 60000 --workers 8            # 默认 --rebuy_lo 16万 --rebuy_hi 160万

# 有门槛的场（按你实际打的场设，例如入场需 450万 / 1800万）：
python -m sanguopai.train_dmc --games 60000 --workers 8 --entry_gate 4500000
```

## ★★★ 计分方式：**默认积分制**（老板 2026-09-14 定："直接搞积分得了，拿 +/- 参与"）

`config.scoring` 两个取值：

| 值 | 结算 | 说明 |
|---|---|---|
| **`"score"`（默认）** | 每个输家对每个第一名各付一份 **`±(牌型 × 暴击 × 名次 × 杀牌)`**，**无封顶、无财富档、不破产、无补豆**（每轮严格零和） | 见下 |
| `"chips"` | `min(L, 1800万, 赢家收款上限, 输家当前豆)` + 财富档 + 破产补豆 | 即本文第二～五节的豆制规则，可切回：`--reward chips` |

**为什么默认积分制**：豆制下 1800万封顶会把"打得好"和"打得差"**抹成同一个数**——
多数局面 `L` 都超封顶（例：三张40 × 同阵营2人 × 第④名12 = 1728万 → 直接顶满），
于是**策略差异被抹平、梯度信号消失**。积分制下差异**直接体现在分数上**，更适合练牌。

**例**（葫芦 100 分赢家、4 家都垫⑤、全同阵营 crit=12、同类只有赢家 kill=1）：

| 输家名次 | 单份积分 = 牌型×暴击×名次×杀牌 | 该家本轮得分 |
|---|---|---|
| ② | 100×12×32×1 = **38,400** | −38,400 |
| ③ | 100×12×24×1 = 28,800 | −28,800 |
| ④ | 100×12×12×1 = 14,400 | −14,400 |
| ⑤ | 100×12×4×1 = **4,800** | −4,800 |
| **赢家合计** | | **+86,400** |

（已在引擎、算牌器、网页 JS 三处逐一对上；每轮零和。）

**积分制下的训练环境简化**：每局 5 人从 0 分开始，**不维护池、不补豆、不破产**——
`--bust_quit` / `--entry_gate` / `--rebuy_lo/hi` 只在豆制下生效。
奖励尺度：`_squash` 自动切到积分尺度（unit=1e3，满格 ≈ 1 万分）。

### ★★★ 破产退出率：才是"牌桌上看不到那么多咸鱼"的主因（2026-09-14 定，老板纠正）

补一句前提：**门槛是 16万（15万）** —— 也就是最低入场 = 补豆额，所以"破产补 16万 继续打"正好等于"回到门槛"。**咸鱼是能进场的**。

那我早前"73% 咸鱼"的模型为什么和体感不符？因为我还有一个更硬的假设：**破产 100% 补豆继续打**。这等价于 **"人人输了就充钱"** —— 老板一句话点破：那平台就赚爆了，现实不成立。

实测（400 局、取后 100 局快照）：

| 破产退出率 | <50万 占比 | 450~1800万 | ≥1800万 占比 | 破产/局 |
|---|---|---|---|---|
| **0%（人人续命 = 我原假设）** | **30.0%** | 2.8% | 35.3% | **3.06** |
| 50%（现默认） | **4.6%** | 2.3% | 90.9% | 1.12 |
| 90% | 1.7% | 3.0% | 91.3% | 0.80 |
| 100%（破产即走） | **1.1%** | 3.6% | 93.2% | 0.75 |

→ **只要"破产退出一半"，咸鱼占比就从 30% 崩到 4.6%（跌 6.5 倍）**。所以真实牌桌咸鱼少，主因是 **输光的人走了、新玩家补位**，而不是门槛。
→ 也顺手回答了"人人输了就充钱"：退出率 0% 时破产 **3.06 人次/局**（每局 3 个人次得充钱），退出率 100% 时只有 **0.75** —— **大部分人输光就走，续命的只是少数**。

### 单局赌注到底多大（折算 ¥，¥10 = 16万豆）

实测 200 局（随机匹配豆、全员贪心）：

| 指标 | 豆 | 人民币 |
|---|---|---|
| 每人每局 \|净输赢\| 平均 | 1209万 | **¥756** |
| 每人每局 \|净输赢\| 中位 | 415万 | ¥260 |
| **输钱的人平均输** | 799万 | **¥500** |
| **每局最大输家平均输** | 14274万 | **¥8922** |
| 单份封顶 | 1800万 | ¥1125 |
| 一局 4 轮理论最高输 | 2.88亿 | ¥18000 |

**入场 ¥10 → 单局平均风险 ¥500（50 倍），最坏 ¥8922（892 倍）。** 这就是老板那句"10 块钱打一把谁受不了，去澳门玩不好"的量化：**澳门允许你小注慢慢磨，这里「450万地板 = ¥281/份」把"小注"这个选项直接删掉了**——最小结算就是 ¥281。

**于是闭环自洽**：多数人受不了这个赌注 → 输光即走 → 池子里的咸鱼自然少 → 老板看到的牌桌"没那么多咸鱼"。

训练参数：

```bash
--bust_quit 0.5    # 破产退出率（默认 50%）；0 = 假设"人人输光就充钱"（不现实，会让池子堆满咸鱼）
```

### 随机匹配：**25 人持久池**（训练环境，必须有）

真实条件是：一个池子里 **25 个 AI 玩家（5 桌 × 5 人）随机匹配**，**豆持久**、**破产补 16 万**继续打。

实现：池子 `pool = 25 × LogU(16万, 1亿)` **建在训练主进程**，每批 `rng.sample(25, 5)` 抽 5 人开一桌（随 payload 把 5 人的当前豆发给 worker），局后把各人终局豆写回 `pool[i]`，`<=0` 置为 `rebuy=16万`。
> ⚠️ 池**必须在主进程**：早前版本建在子进程 `_actor` 里 → 每批重置 = "持久"名存实亡，学不到"我穷且会一直穷"。

> ⚠️ **不要用"每局重抽 5 个随机豆"代替**——那是**在错误的分布上做精细优化**。实测两者差距巨大：

| 财富档 | **25人持久池（稳态，后100局快照）** | 每局重抽（对数均匀） |
|---|---|---|
| <50万 | **73.3%** | 17.9% |
| 50~450万 | 4.4% | 34.2% |
| 450~1800万 | 3.2% | 21.6% |
| 1800万~1亿 | 12.4% | 26.2% |
| >1亿 | 6.7% | 0% |
| 中位数 | **16万（补豆地板）** | 约 400万 |
| 破产补豆 | **3.6 人次/局** | — |

→ 真实牌桌上**七成以上的人常年压在 16万 地板**。只按均匀采样训练，模型会被训成"只会打富局"，上桌就废。

其他配套：
- **回报压缩**：`t = sign(Δ)·log1p(|Δ|/1e5) / log1p(4×cap/1e5)`，把 `|Δ豆| ∈ [0, 7200万]` 压到 `[-1,1]`。保序（同一决策内 argmax 不变），但让"穷座位输光(−0.036×cap)"与"富座位赢满(+4×cap)"的梯度同量级——直接除以 scale 的话两者差约 100 倍，MSE 会被高豆样本主导。
- **评估**：固定 32 组豆表（固定种子）+ DMC 座位在 5 个位置**轮换**（避免位置偏差）+ 固定种子（CRN）→ 每次评估同一批局面，可横向比较。
- 网页 `game.html` 的「重置池」同样是随机匹配（16万~1亿各自抽、**保证互不相同**），豆随局数累积、破产补 16 万。
