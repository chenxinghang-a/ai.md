# 本地模拟实操 · 把游戏原文件（含非官方 mod）导入平板

> 适用：vivo Pad6 Pro（骁龙8 Elite Gen5 / **Adreno 840** / 12+256 / OriginOS 6 / **无 microSD 卡槽，有 USB 3.2 OTG**）
> 你的现状：无实体 Switch（ROM 是 yuzu 时期攒的）、PC 串流用盖世游戏 GameHub、云游不要、主要玩**本地模拟**。

---

## 0. 先说结论（给你这种人）

1. **存储是头号问题**：256GB 焊死、不能插卡。解决办法只有一个——**USB-C 接外置 SSD/优盘（OTG）**，把游戏库放外面，模拟器直接扫 OTG 路径。别想着全塞进内置存储。
2. **Switch 本地模拟用 Eden**（yuzu 已死但 Eden 同根，你的 ROM 直接能用）。导入分三样东西：ROM 本体、mod、更新/DLC，走不同入口。
3. **PC 本地模拟用 GameHub（盖世游戏）**：它本质是个"自动配好驱动的 Winlator"。导入游戏 = 把整个游戏文件夹（含 mod）指给它，**mod 和 PC 上一样处理**。
4. **驱动**：Adreno 840 要用新版 Turnip。Eden 用内置"驱动获取器"自动装；GameHub 导入时自动下配置，基本不用你管。

---

## 1. 存储方案（最重要的一步）

- 买/找个 **USB-C 移动固态（SSD）** 或高速优盘，格式化成 **exFAT**（安卓和 Windows 都认、支持大文件）。
- 平板支持 **USB OTG**（USB 3.2），插上直接在文件管理器里能看到。
- **推荐做法**：游戏全部放 OTG 盘，Eden/GameHub 直接把"游戏文件夹"指向 OTG 路径。这样 256GB 内置只装模拟器本体，游戏库想放多少放多少。
- 退路：实在要放内置，也行，但 Switch 游戏单个体 5–30GB、PC 游戏更大，两三个就满。

文件进平板的三条路（任选）：
- **OTG 直拷**（最稳）：PC 上把文件放进 SSD → 插平板 → 用文件管理器或模拟器自带文件浏览复制/直接指向。
- **局域网传**：PC 和平板同 Wi-Fi，用 **LocalSend**（开源、零配置）或文件管理器的 SMB/LAN 互传。
- **云盘中转**：小文件可，大文件不建议（慢且费流量）。

## 2. Switch 本地模拟：Eden 导入 ROM + mod + 更新/DLC

### 2.1 先备齐环境
- 装 **Eden**（Google Play 或官网 APK）。
- 你 yuzu 时期应该有 `prod.keys` 和固件——直接复用。没有就按 Eden 首次启动引导导入（密钥需自行获取，固件建议 **19.0.1**）。
- 装好后在 Eden 里用**驱动获取器**装对应 Adreno 840 的 Turnip 驱动（认准 A7xx 以上）。

### 2.2 导入 ROM 本体（"游戏原文件"）
- Eden 主界面 → 齿轮 → **管理游戏文件夹** → 点 "+" 选你放 ROM 的目录（可以是 OTG 盘上的文件夹）。
- 支持 **NSP / XCI / NSZ**。扫完游戏自动出现在列表。
- 你的 yuzu ROM 直接能用，无需转格式。

### 2.3 导入非官方 mod（重点）
> 原理：Eden 用 LayeredFS，每个游戏有自己的 mod 目录，mod 以"独立子文件夹"形式放进去，互不冲突。

**普通 mod（绝大多数）：**
1. 游戏列表里**右键（或长按）→ "Open Mod Data Location"（打开 mod 数据位置）**。这一步 Eden 会直接打开该游戏的正确 mod 文件夹（Android 上在应用私有目录里，不用你记路径）。
2. 把 mod 解压，**每个 mod 单独放一个子文件夹**进去。
   - 若 mod 里带 `exefs/` 或 `romfs/` 文件夹（Atmosphere 格式），连同这两个文件夹一起放进你建的 mod 子文件夹。
3. 重启 Eden → 右键游戏 → **Configure Game（配置游戏）→ Add-Ons（附加内容）** 标签页，勾选启用对应 mod。
4. 启动游戏，mod 生效。

**框架类 mod（如《任天堂明星大乱斗》用 ARCropolis）：**
- 这类不走普通 mod 文件夹，要装到**模拟 SD 卡**：`sdmc/atmosphere/contents/<游戏title_id>/`。
- 同样用 Eden 的"打开 SD 卡位置"（emulated SD）菜单进入，按 mod 说明把 `atmosphere` 文件夹放进去。
- 注意：别把框架 mod 塞进普通 `load/` 文件夹，不生效。

### 2.4 导入更新 / DLC（也是"非官方文件"常见来源）
- 更新和 DLC 是 **NSP 文件**，不走 mod 文件夹，走系统安装：
- 菜单 **File → Install Files to NAND**（安装文件到 NAND）→ 选 NSP。
- **顺序必须：本体 → 更新 → DLC**，错序可能装不上。
- 装完右键游戏 → 属性/Add-Ons 里能看到版本号和已装 DLC。

> 一句话区分：mod = 放 mod 文件夹（Open Mod Data Location）；更新/DLC = 装到 NAND（Install Files to NAND）。别混。

## 3. PC 本地模拟：GameHub（盖世游戏）导入游戏 + mod

GameHub 本质 = 自动配好 Turnip/DXVK 的 Winlator。它**直接跑 Windows 游戏文件**，所以"含 mod 的游戏"处理方式和真 PC 一模一样。

### 3.1 导入流程
1. 平板装 GameHub（Play 商店或官网），登录账号。
2. 把**整个游戏文件夹**（内含游戏 .exe + 所有游戏文件 + 你已经放好的 mod）弄进平板（OTG 盘或内置）。
   - 关键：mod 在 PC 上怎么放，在平板里就怎么放。比如：
     - 文件替换型 mod → 直接覆盖/放进游戏目录对应位置；
     - 有独立 `Mods/` 文件夹的游戏 → 原样放；
     - 需要 modloader（如某些游戏的启动器/补丁 exe）→ 一起带进来。
3. GameHub 里用**库导入 / 1-Click Import**，指向那个游戏文件夹。
4. GameHub 会自动扫描并下载该游戏的**优化驱动/固件配置**（这就是它比裸 Winlator 省心的地方），然后生成启动项。
5. 启动 → 进游戏后 mod 按 PC 上的规则生效。

### 3.2 需要打补丁/跑 modloader 的情况
- GameHub 给每个游戏一个类 Winlator 的 Windows 容器（有桌面）。
- 如果 mod 需要先运行一个安装器/补丁程序，先进那个容器的"桌面"模式，像在 PC 上一样双击运行安装器，再回到游戏启动。
- 手柄：GameHub 对手柄震动/映射做得好，接蓝牙手柄即可。

### 3.3 能跑什么 / 跑不动什么
- **能跑**：老游戏、DRM-free（GOG 版）、无反作弊的——辐射 NV、老滚4、GTA4/5、丝之歌这类。
- **跑不动**：带 Denuvo / Easy Anti-Cheat / 内核级反作弊的现代 3A——反作弊会识别翻译层直接拦掉，**不是你设备问题，别硬刚**。这类就回到 Moonlight 串流（你有电脑的话）。

---

## 4. 驱动与系统设置提醒

- **GPU 是 Adreno 840**（不是 830），务必用对应新版 Turnip（A7xx 系列以上）。Eden 驱动获取器会推荐对的；GameHub 自动处理。
- OriginOS 6：把 Eden / GameHub 加入**"不受电池优化限制"**（设置→电池→应用省电策略），否则后台被杀、串流/模拟中断。
- 散热：8 Elite 满载会降频，玩时摘壳、别边充边玩。

---

## 5. 给你的上手顺序（省时间版）

1. **先搞定存储**：弄个 USB-C SSD（exFAT），把 yuzu ROM 和想玩的 PC 游戏文件夹先搬上去。这是地基。
2. **Eden 跑通一个 Switch 游戏 + 一个 mod**：装 Eden → 导入 keys/固件 → 指 OTG 上的 ROM 目录 → 试《空洞骑士》这类轻量作 → 再练一次"Open Mod Data Location"塞个 mod，验证流程。
3. **GameHub 跑通一个老 PC 游戏 + mod**：导入一个 GOG 无 DRM 游戏（已带 mod 文件夹）→ 看自动配置是否顺利。
4. 之后就是批量往 OTG 盘里加游戏，按需导入。

> 注：游戏文件与 mod 需为你合法拥有的副本；本文只讲"导入与运行"的技术流程，不提供任何 ROM/密钥/游戏下载渠道。非官方 mod 来源自行甄别安全性。
