# 05 · 有了香港银行账户之后，内地大学生能用它做什么投资

> **调研日期**：2026-09-16
> **用户画像**：中国大陆大学生，电气工程专业，无资产、无收入、无工作，可用闲钱约 5,000–30,000 元人民币，风险承受能力低。
> **本报告立场**：客观说明**真实门槛**与**真实成本**，很多产品他根本够不着，会直说。

---

## ⚠️ 三条必读声明

1. **费率时效性**：本文所有费率均为 **2026 年 9 月可查证的最新公开数据**，来源已标注年份。金融市场费率变动频繁，**交易前必须以各机构官网最新公告为准**。
2. **合规性分工**：本文仅做简要风险提示，跨境证券合规细节由**政策组**负责，请勿以本报告替代专业法律意见。

## 0. 核心结论速览（先看这一节）

| 问题 | 2026 年 9 月的真实答案 |
|---|---|
| 内地学生能开富途/老虎/长桥吗？ | **不能。** 三家已于 2026-06-12 起对存量内地账户执行「**仅卖出、仅出金**」，新开户通道对纯内地身份**已关闭** |
| 能开 IBKR 盈透吗？ | **不能。** 2025 年 9 月起纯内地身份证持有者无法新开户 |
| 能开 Firstrade / 嘉信吗？ | **理论上可以**（护照开户），但**入金必须走境外同名银行账户**——这正是港卡的价值所在 |
| 那港卡到底有什么用？ | **最大的价值是银行自带证券账户**，尤其**汇丰 Trade25（18–35 岁）**：每月 HK$25，港股/美股/A股 **$0 佣金 + $0 平台费** |
| 1 万元人民币实际能做什么？ | ① 汇丰 Trade25 买港股/ETF；② 港卡定存（港元 2.4%、美元 3.3%）；③ 美元货币基金。**仅此三项现实可行** |
| 全链路往返成本 | **约 3.5%–4.5%**（1 万元人民币单次买卖往返） |

## 1. 2026 年最重要的前提：券商通道已经关闭

这是本次调研中**最关键的发现**，直接改变了对「港卡能做什么」的答案。很多 2024–2025 年的攻略文章已经**完全过时**。

### 1.1 政策时间线

| 时间 | 事件 | 对内地学生的影响 |
|---|---|---|
| 2016-07 | 证监会首次点名富途、老虎未经批准提供境外证券交易服务 | 风险提示阶段 |
| 2021-10 | 央行金融稳定局定性跨境互联网券商为「无照驾驶」非法金融活动 | — |
| 2022-12-30 | 证监会认定富途、老虎构成**非法经营证券业务**，提出「遏制增量、化解存量」 | 停止新开户 |
| 2023-05 | 富途牛牛、老虎国际 App 从**中国境内应用商店下架** | 无法在内地下载 |
| 2025-08/09 | IBKR 要求新开户内地申请人提供**境外工作或生活证明**；随后确认纯内地身份无法开户，App 从中国区下架 | **IBKR 对内地关闭** |
| 2025-06~09 | 长桥停止内地用户通过「存量证明」开户；富途要求海外永居身份；老虎仅接受持非内地身份证件客户 | 全线收紧 |
| **2026-05-22** | 证监会等**八部门**联合印发《综合整治非法跨境证券期货基金经营活动实施方案》（证监发〔2026〕28 号）。同日对**富途（拟罚没约 18.5 亿元）、老虎（约 4.11 亿元）、长桥**立案调查并作出行政处罚事先告知 | **制度性终结** |
| **2026-06-12** | 富途、老虎、长桥开始对**存量境内投资者账户执行「仅卖出、仅出金」**：暂停买入、加仓及资金转入 | 存量用户单向退出 |
| **2026-07-01** | 《国务院关于对外投资的规定》（国务院令第 837 号）生效，**居民个人首次被正式纳入境外投资监管范围** | 个人跨境投资进入监管框架 |

|---|---|---|

### 1.3 官方推荐的「合法渠道」及其对学生的实际门槛

| 合法渠道 | 门槛 | 学生能否够到 |
|---|---|---|
| 港股通 | 证券账户资产**前 20 个交易日日均不低于 50 万元人民币** | ❌ 完全够不到 |
| QDII 基金 | A 股账户即可，10 元起投（部分限购） | ✅ **可行**，但不能自己选个股 |
| 跨境理财通（南向通） | 具 2 年以上投资经历，且近 3 个月家庭金融净资产月末余额**不低于 100 万元人民币** | ❌ 完全够不到 |

**结论：对无资产学生而言，官方渠道里唯一现实可行的是 QDII 基金（在内地就能买，和港卡无关）。**

### 2.2 关键差异解读

**① 「免佣」不等于「免费」**

互联网券商的商业模式是：**免佣金 + 收平台费**。以买 2 手腾讯（约 HK$60,000）为例：

| 项目 | 富途 | 老虎（固定式） | 长桥 | 汇丰 Trade25 |
|---|---|---|---|---|
| 佣金 | HK$0 | HK$0 | HK$0 | HK$0 |
| 平台费 | HK$15 | HK$15 | HK$15 | HK$0 |
| **券商端合计** | **HK$15** | **HK$15** | **HK$15** | **HK$0**（月费另计 HK$25） |

**对小额学生而言，单笔 HK$15 平台费反而比佣金更痛**。买 HK$1,000 的股票，HK$15 就是 **1.5%** 的成本。

**② 汇丰 Trade25 是小额用户的性价比之王**

| 项目 | 内容 |
|---|---|
| 适用年龄 | **18–35 岁**（2026 年已从原 18–25 岁扩展至 35 岁，需在 2026-06-30 前完成首宗合资格交易享受 HK$1,000 Apple Store 礼券优惠） |
| 月费 | **HK$25**，且**仅在该月有买卖或持有股票时才收**（当月无交易无持仓则不收） |
| 港股佣金 | **HK$0**（每月交易额 ≤ HK$250,000） |
| 美股佣金 | **US$0** |
| A 股佣金 | **RMB 0** |
| 平台服务费 | **HK$0** |
| IPO 认购手续费 | **HK$0** |
| 超限后 | 月交易额 > HK$250,000 时，此后按 0.25%（最低 HK$100）/ 美股首 1,000 股 US$18 收取 |
| 26 岁以上续享条件 | 每年 1 月 1 日已满 26 岁者，**该年须完成至少 25 笔交易**方可续享下一年优惠 |

**算一笔账**：学生一个月做 2 笔交易（买 1 次 + 卖 1 次）：
- Trade25：HK$25
- 富途/老虎：HK$15 × 2 = HK$30
- 长桥：HK$15 × 2 = HK$30
- 渣打：每笔最低 HK$50，2 笔 = HK$100

→ **Trade25 明显更优，且交易越频繁优势越大**（10 笔交易：Trade25 = HK$25 vs 竞争对手 ≥ HK$150）。

**③ 一个坑：Trade25 的月费按「持有」也收**

「只要您的账户曾**买卖或持有**股票，便须为该月缴付 HK$25」。也就是说，**长期持有不动，每月照样扣 HK$25**。持有一年 = HK$300。对 HK$10,000 的仓位，这是 **3%/年** 的隐性成本。

> ⚠️ 如果学生打算「买入后长期不动」，Trade25 反而可能不划算；这种情况下应计算持仓市值对应的费率。

**④ 美国券商的隐性门槛：入金路径**

- **Firstrade**：不接受 Wise / Revolut / PayPal / Western Union 等第三方汇款，必须是**传统银行的电汇**。港卡电汇美元到 Firstrade（收款行为 Apex Clearing），到账 1–3 个工作日。
  - **汇款补贴**：开户 30 天内首次单笔 ≥ US$2,500 可申请补贴一次，上限 US$25；此后单笔 ≥ US$10,000 可申请，每月 3 次，每次上限 US$25。
  - ⚠️ 但**部分用户反馈 Wise 有时可成功**，规则存在不确定性。
- **嘉信 Schwab**：
  - 出金电汇费 **US$15/笔**；若选港元收款，**嘉信会做货币兑换并收取最高约 3% 的汇率点差**——这是一个非常贵的坑，务必选美元汇出。
  - 香港银行账户可直接汇港币到嘉信的花旗账户，汇款后自动兑换为美元入账（该账户也支持 FPS）。
  - 大陆用户**无法申请 Visa 借记卡**。

### 4.5 保险 / 储蓄险（银行最爱推销，重点分析）

#### 真实收益结构

| 组成部分 | 性质 | 实际水平 |
|---|---|---|
| **保证现金价值** | 合同刚性兑付 | **保证 IRR 仅 0.5%–1.5%**，占总价值比例很低 |
| **复归红利（周年红利）** | 宣告后永久归属，不会回溯扣减 | 非保证 |
| **终期红利** | 收益占比最高，**退保/理赔才全额发放** | 非保证，中途支取有折价损耗 |

#### 市场主流产品宣传 vs 真实情况

| 项目 | 宣传口径 | 真实情况 |
|---|---|---|
| 长期 IRR | 「6%–7% 复利」 | 这是**非保证的演示收益**（中档情景），且需要持有 **20–30 年** |
| 回本时间 | 「第 6–8 年回本」 | **含分红**的预期回本；**纯保证部分回本周期极长**。行业研究显示香港终身寿险**回本平均需 9–10.8 年** |
| 分红实现率 | 「长期 100%+」 | 保监局 GN16 强制披露，行业长期实现率 85%–105%；**约四成香港分红险产品曾未能 100% 达成收益目标** |
| 早期退保 | 未突出说明 | **前 1–2 年退保可能仅拿回保费的 10%–30%**（部分产品前 2 年退保无任何返还）；前 5–8 年是「锁定期」 |

#### 五大「坑」

1. **非保证 ≠ 一定能拿到**：计划书上的高收益全部来自分红池投资盈余分配，合同保证的只有 0.5%–1.5%。
2. **流动性极差**：资金需长期锁定，中途退保可能亏本金 50%+。
3. **断供风险**：供款期 5–20 年以上，一旦失业/财困断供，保单可能提前终止，且初期退保金额低于已缴保费。
4. **强制赴港面签**：内地居民必须**本人亲赴香港**在保险公司或认可场所签约，否则属于**「地下保单」，不受法律保护**。冷静期 21 个自然日。
5. **汇率风险**：多为美元/港币计价，人民币若升值，折算回人民币的实际收益会缩水。且涉及购汇缴费与将来理赔金结汇，受每年 5 万美元便利化额度约束。

#### 对学生的一句话结论

> ❌ **香港储蓄险对无收入、无资产、可能近几年就要用钱的大学生，是绝对错误的产品。**
>
> 这类产品的适配画像是「家庭年收入 50 万以上、有 100 万以上闲置资金、能确保 15–30 年不动用」。学生连「15 年不动用」这个前提都无法保证。行业分析明确指出不适合人群包括「5–10 年内有买房、创业、育儿等大额资金支出」以及「把长期复利工具当成短期理财」者。
>
> **银行客户经理推销储蓄险时，只需回一句：「这笔钱我 3 年内要用。」**

### 4.6 结构性产品（风险极高，学生应远离）

#### 典型产品：股票挂钩投资 ELI / 股票挂钩票据 ELN

**运作逻辑**（以 HK$10 万本金、挂钩某蓝筹股、现价 HK$100、行使价 HK$90 为例）：

| 情景 | 到期结果 |
|---|---|
| 股价 ≥ 行使价 | 收回 100% 本金 + 利息 |
| 股价 < 行使价 | **被迫用 HK$90 的高价接下当时可能只值 HK$50 的股票**（「接货」） |
| 股价跌至 0 | **损失 100% 本金** |

**主要风险（据香港投资者及理财教育委员会 IFEC 与金管局）**：

| 风险 | 说明 |
|---|---|
| **不保本** | 「股票挂钩投资并不保本……在极端情况下，你可能损失全部投资款项」 |
| **收益有上限** | 「潜在收益可能限于发行商所预设的一个上限」——赚有限，亏无限 |
| **发行商信用风险** | 无抵押、无担保，若发行商违约或无力偿债，**可能损失全部投资** |
| **流动性风险** | 设计为持有至到期，只提供有限度庄家活动；提前终止「可能远低于初始投资额」 |
| **不受保障** | 不在交易所上市，**不受投资者赔偿基金保障**；不属于受保障存款，不受存保计划保障 |
| **费用高** | 实物结算时还要付印花税、交易征费、登记费 |
| **分销商风险** | 需倚赖分销银行派发通知与付款，银行违约时要向其追索 |

#### 银行如何推销这类产品

银行客户经理通常会强调「**高息**」（如年化 12%）、「**大概率不会跌**」、「**就算接货也是趁低吸纳**」。但金管局的官方科普直接反驳了这套话术：

> 「如果 ELN 埋单当日，股价跌到 50 元，你都要被逼用 90 元『高价』接货，即刻『坐艇』，点会係趁『低』吸纳呀！……即係有机会赢得少、输得多。」——香港金管局「小森阿四专栏」

#### 学生结论

> ❌ **绝对不要碰。** 这类产品的最低投资额通常在 HK$10 万以上（部分银行 HK$5 万起），学生本来就够不到；更重要的是，**风险收益不对称（赢有上限、输无下限），且需要「专业投资者」级别的认知**。产品说明书本身就是几十页的法律文件。

**隐性成本：汇率差距**

> 手续费只是可见成本。**汇款到内地的另一大成本是外汇点差**——银行使用的汇率通常与市场中间汇率有差距，这个差距是银行的收入来源之一，**并不在手续费栏显示**。

**两种回流方式对比**

| 方式 | 操作 | 成本结构 | 限额 |
|---|---|---|---|
| **以人民币（CNH）直接汇出** | 先在香港把港元换成人民币，再汇至内地 | 香港换汇点差 + 电汇手续费 | 受**人民币 80,000 元每日**同名账户限制 |
| **以港元汇出，内地收款人结汇** | 直接汇港元，内地银行结汇 | 内地银行换汇点差 + 电汇手续费 + 中间行费 | 结汇受**年度 5 万美元**便利化额度约束 |

> ⚠️ **合规红线（据外管局 2026-01 风险提示）**：
> - 拆分汇款规避额度会被多维度数据比对监测，情节严重可**取消个人年度便利化额度**，并按《外汇管理条例》第四十八条处**违法金额 30% 以下罚款**。
> - **虚假申报用途**（如把投资收益填成旅游、礼品）一旦被监测发现，资金原路退回，且**3 年内不得享受个人外汇便利化服务**。
>
> ⚠️ **重要澄清**：年度 5 万美元等值便利化额度是「**无需提供材料即可办理结汇**」的额度，**并非个人每年可接收境外汇款的上限**。合法经常项目所得、能提供真实性证明材料的，接收金额不受此限。

## 6. 合规性（简要，细节由政策组负责）

### 6.1 内地居民用港卡投资港股/美股的合法性

| 维度 | 现状（2026-09） |
|---|---|
| **境外机构在境内招揽开户** | ❌ **明确非法**。八部门《整治方案》认定构成「非法跨境经营活动」，全面取缔 |
| **境内资金出境炒证券** | ❌ **违反外汇管理规定**。购汇用途不得填「证券投资」；个人私自换汇出境炒股「属于违规，资金不受国内法律保护」 |
| **境外机构向位于境外的境内投资者提供服务** | ⚠️ 官方明确「**并未限制**」（人民网，2026-05-22）。即人已在香港境内办理，性质与境内被招揽不同 |
| **香港银行证券账户** | ⚠️ 香港持牌银行提供的证券服务，受 SFC/金管局监管。但**不受香港投资者赔偿基金（ICF）保障**，且资金出入境仍受外汇管理约束 |
| **个人境外投资监管** | 🆕 2026-07-01 起，《国务院关于对外投资的规定》（国务院令第 837 号）生效，**居民个人首次被正式纳入境外投资监管范围** |

### 6.2 学生必须知道的三条「不要做」

1. **不要伪造材料开户。** 富途表示「过去两年间驳回数以万计不符合规则的开户申请」，香港证监会 2026-05-22 通函明确要求持牌法团「关闭以可疑或伪造文件开立的投资账户」。造假开户可能构成刑事犯罪。
2. **不要用「存量证明」等灰色渠道。** 长桥已明确停止内地用户通过「存量证明」开户；这类操作属于整治对象。
3. **不要做虚假汇款用途申报。** 后果见 5.3 节，可导致额度取消 + 罚款 + 3 年关注名单。

## 8. 不要碰的清单

| 产品 | 为什么不要碰 | 学生真实门槛 |
|---|---|---|
| **杠杆/融资（孖展）** | 放大亏损，可能被强制平仓（force selling）甚至倒欠。港股孖展年利率 6.8%，美股 4.8%——**借钱成本高于多数人的投资能力** | 部分券商开户即可开通，门槛低反而危险 |
| **期货** | 高杠杆、有到期日、可能亏损超过本金 | 需单独申请权限 |
| **期权（买方）** | 时间价值每天流失，多数期权到期归零 | 门槛低，但**归零概率高** |
| **期权（卖方）** | 收益有限、亏损无限 | ❌ 绝对禁止 |
| **牛熊证 / 窝轮（权证）** | 有收回机制（强制赎回），高杠杆，**可能一夜归零** | 富途/老虎等 App 内一键可买，**这是最容易踩的坑** |
| **结构性产品（ELI/ELN/DCI）** | 不保本、收益有上限、亏损无下限、发行商信用风险、不受 ICF 保障。金管局官方原话：「有机会赢少输多」 | 通常 HK$50,000–100,000 起，学生多数够不到 |
| **储蓄险 / 分红险** | 保证 IRR 仅 0.5%–1.5%；前 1–2 年退保仅拿回 10%–30%；回本平均需 9–10.8 年；必须赴港面签否则是「地下保单」 | 年缴门槛通常 US$3,000–10,000 起，学生够不到，**但客户经理会诱导分期** |
| **加密货币 / 虚拟资产** | 24 小时波动，无涨跌停，监管不确定 | 部分平台已开放给零售，需通过知识测试 |
| **非投资级债券（高收益债/内房债）** | 违约风险高 | 门槛 10 万美元起，够不到 |
| **私募 / 对冲基金** | 需「专业投资者」身份（个人资产 ≥ HK$800 万） | ❌ 完全够不到 |
| **「保证高息」的陌生平台** | 多为民间的非法集资或诈骗 | ❌ 直接远离 |
| **代他人操作 / 出借账户** | 涉嫌违法，且需承担全部法律责任 | ❌ |

> ⚠️ **额外提醒**：香港证监会 2026-05-22 通函要求持牌法团「**关闭零结余不动投资账户**」，以「纾减该等账户被不法分子用作进行非法活动的潜在风险」。**不要把不用的账户借给他人或长期空置。**

## 9. 总成本测算

### 9.1 场景设定

**张同学**：内地大学生，有 10,000 元人民币闲钱，已有汇丰香港账户，决定用港卡买 1 手中国银行（3988）试水，持有 2 个月后卖出，资金汇回内地。

**汇率假设**（2026-09-16 参考）
- 中间价：1 HKD = 0.8621 CNY
- 银行港元卖出价（买港元）：1 HKD = 0.8680 CNY
- 银行港元买入价（卖港元）：1 HKD = 0.8560 CNY

### 9.2 全链路成本明细

| 步骤 | 操作 | 计算 | 金额 |
|---|---|---|---|
| **① 内地购汇 + 汇出** | 10,000 CNY → HKD，跨境汇款至港卡 | | |
| | 汇兑（按 0.8680） | 10,000 ÷ 0.8680 = **11,521 HKD** | 隐含成本 ¥70 |
| | 内地银行跨境汇款手续费 | 约 ¥100 | ¥100 |
| | 电报费 | 约 ¥80 | ¥80 |
| | 中间行费（港币汇香港，通常无） | HK$0 | ¥0 |
| | **①小计** | | **¥250（2.50%）** |
| **② 港卡 → 券商** | 汇丰 Trade25 是银行内账户，无需转账 | HK$0 | ¥0 |
| **③ 买入 1 手中国银行** | | | |
| | 假设买入 1,000 股 @ HK$5.00 = **HK$5,000** | | |
| | 印花税 0.1%（向上取整） | HK$5.00 | ¥4.31 |
| | 交易费 0.00565% | HK$0.28 | ¥0.24 |
| | 证监会交易征费 0.0027% | HK$0.14 | ¥0.12 |

| **合计** | | | **¥377.84** |

### 9.3 成本汇总

| 成本类别 | 金额 | 占比 |
|---|---|---|
| 内地购汇 + 汇出 | ¥250 | 2.50% |
| 港股买入硬性费用 | ¥4.86 | 0.10% |
| Trade25 月费（2 个月） | ¥43.11 | 0.43% |
| 港股卖出硬性费用 | ¥4.86 | 0.10% |
| 港卡 → 内地汇款 + 结汇 | ¥70 | 0.70% |
| **合计** | **¥377.84** | **3.78%** |

### 9.4 不同方案的往返成本对比

| 方案 | 往返总成本 | 占比 | 说明 |
|---|---|---|---|
| 港卡定存（不动） | ¥250（仅搬入） | 2.50% | 若最终要汇回再加 ¥70 = 3.20% |
| **汇丰 Trade25 买港股（持 2 个月）** | **¥378** | **3.78%** | 本文基准方案 |
| 汇丰 Trade25 买港股（持 1 个月） | ¥356 | 3.56% | 月费少 1 个月 |
| 汇丰 Trade25 买港股（持 12 个月） | ¥485 | 4.85% | 月费 ×12 是主要拖累 |
| 用富途/老虎买港股（2 笔平台费） | ¥356+52 = ¥408 | 4.08% | 已无法开户，仅对比 |
| 用渣打银行买港股 | ¥250+70+¥86(2×50HKD)+¥70 = ¥476 | 4.76% | 最低 HK$50/笔吃掉收益 |
| **美股（Firstrade，持 1 年）** | 约 ¥695 | **6.95%** | 两层换汇 + 两次电汇 |
| 银行买基金（认购费 3%） | ¥250+300+70 = ¥620 | **6.20%** | 认购费是最大头 |

### 9.5 关键结论

1. **单次往返成本约 3.5%–4.8%**。意味着投资的标的**至少要涨 4% 才回本**。
2. **最大的两块成本在内地端（购汇汇出 2.5%）和回流端（结汇 0.7%）**，合计约 3.2%，**与投什么产品几乎无关**。
3. **Trade25 月费对短持有期影响小，对长持有期影响大**。持有 12 个月，月费成本从 0.43% 升到 2.58%。
4. **省钱三原则**：
   - **减少往返次数**：不要小金额频繁进出，一次规划好
   - **缩短中间环节**：不要太频繁交易（省平台费/佣金）
   - **选对回流渠道**：中银香港「中银快汇」免费，比分行电汇省 HK$150–250
5. **如果只是「尝试一下」，成本太高。这笔钱应该先在内地做 QDII 基金，成本几乎为零。**
