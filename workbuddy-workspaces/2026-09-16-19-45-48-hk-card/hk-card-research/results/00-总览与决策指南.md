> **调研时点**：2026-09-16　|　**对象**：中国大陆大学生（无资产、无收入、无工作）
> 本报告由 6 路并行调研合成，明细见 `results/01`～`06`。

## 二、那到底还开不开？—— 一句话判断

> **把它当"境外账户基础设施"开，别当"投资工具"开。**

| 你的情况 | 建议 |
|---|---|
| 不炒港股、不收境外款、不海淘、不留学 → **只是"听说港卡香"** | ❌ **别开**。开了就是睡眠户，还要防被收费、防被关 |
| 计划留学 / 赴港工作 / 收外币稿费兼职 / 想配点美元 | ✅ **开 1 家就够**（首选见下） |
| 想用港卡入金港美股 | ⚠️ **先读第 4 节再说**——券商端已关门，成本也不划算 |
| 只有 1 万元闲钱想"试试投资" | ❌ **别搬钱过去**。往返摩擦成本 3.5%–7%，内地买 QDII 基金成本≈0 |

## 四、有了港卡，能做什么投资？（诚实版）

### 4.1 券商端：门已经关了

| 机构 | 内地新客（2026-09） | 存量内地客户 |
|---|---|---|
| 富途 / 老虎 / 长桥 | ❌ 全面停止 | **仅卖出、仅出金**（2026-06-12 起） |
| IBKR 盈透 | ❌ 2025-09 关闭 | 要求补境外地址证明 |
| 华盛 / 微牛 | ❌ 已下架境内 App | 受限 |
| Firstrade / 嘉信（美国） | ⚠️ 护照可开，**入金必须境外同名银行卡** | 可用 |

### 4.2 银行自带证券账户：唯一现实通道

**汇丰 Trade25**（18–35 岁）——每月 **HK$25**，港股/美股/A 股 **$0 佣金 + $0 平台费**（月交易额 ≤ 25 万港币）。
- 算账：一个月买 1 次卖 1 次 → Trade25 = HK$25；富途/老虎 = HK$15×2 = HK$30；渣打 = HK$50×2 = HK$100。
- ⚠️ **坑**：月费按"曾买卖**或持有**"就收，长期持有不动每月照样扣 25，持有一年 = HK$300（对 1 万仓位是 3%/年）。

### 4.3 现实门槛（很多产品你根本够不到）

| 产品 | 真实门槛 | 学生够得着吗 |
|---|---|---|
| 港股（每手股数） | 腾讯一手 100 股 ≈ HK$60,000；汇丰 400 股 ≈ HK$40,000；中行 1,000 股 ≈ HK$5,000 | ⚠️ 只有低价股够得着 |
| 美股 ETF（VOO 等） | **1 股起**，约 US$100–600，佣金 US$0 | ✅ 但是要美元 + 电汇 |
| 港卡定期存款 | **象象/富融 1 元起，12 个月 3.00%–3.15%** | ✅ 唯一零门槛 |
| 银行代销基金 | 认购费 **2%–5%** + 管理费 1%–2%/年 | ❌ 3% 认购费直接吃掉收益 |
| 债券（单只） | 5 万–100 万美元起 | ❌ |
| 储蓄险 / 分红险 | 保证 IRR 仅 **0.5%–1.5%**；前 1–2 年退保只拿回 10%–30% | ❌ **绝对错误的产品** |
| 结构性产品 ELI/ELN | 5 万–10 万港币起，不保本、收益封顶、亏损无下限 | ❌ 不要碰 |
| 私募 / 对冲基金 | 个人资产 ≥ HK$800 万 | ❌ |

### 4.4 全链路成本（1 万元人民币买港股，持 2 个月再汇回）

| 环节 | 成本 |
|---|---|
| 内地购汇 + 汇出 | ¥250（2.50%） |
| 港股买入硬性费用（印花税等 0.11%） | ¥4.86 |
| Trade25 月费 × 2 | ¥43 |
| 卖出硬性费用 | ¥4.86 |
| 港卡 → 内地（中银快汇免费）+ 结汇点差 | ¥70 |
| **合计** | **¥377.84 ≈ 3.78%** |

> **换成美股（Firstrade）≈ 6.95%；银行买基金 ≈ 6.20%。**
> **核心结论：标的至少涨 4% 才回本，而这 3.2% 的成本和投什么产品几乎无关（都在购汇与回流两端）。**

## 五、红线清单（必须背下来）

### ⛔ 明确不要做

| 禁止事项 | 后果 |
|---|---|
| 用便利化购汇（旅游/留学名义）购汇后投境外证券 | 违反《个人外汇管理办法》第七条；《外汇管理条例》第 39 条，**罚逃汇金额 30% 以下**+ 关注名单（当年及之后 2 年无额度）；情节严重可涉骗购外汇罪 |
| 分拆购汇 / 借用他人额度 / 出借本人额度（"蚂蚁搬家"） | 同上，有组织可涉刑 |
| 地下钱庄 / 对敲换汇 / 虚拟货币（USDT）跨境转移 | 行政：没收违法所得 + 罚款（可达违法金额 30% 以上等值）；刑事：非法经营罪（特别严重 5 年以上）、洗钱罪 |
| 伪造境外身份 / 地址证明 / 资金证明开户 | 账户被关、资金可能冻结；香港证监会 2026-05-22 通函明确"零容忍" |
| 找非法中介"包开户" | 中介本身是八部门整治对象（证监发〔2026〕28 号点名） |
| 出租 / 出借 / 出售银行卡（含港卡）或"帮人收款走账" | 断卡行动惩戒（5 年暂停非柜面业务）+ 征信污点；可能构成**帮助信息网络犯罪活动罪**（3 年以下） |
| 境外所得不申报 | 补税 + 滞纳金（日万分之五）+ 罚款（未缴税款 50%–5 倍）；追征期 3 年，少缴超 10 万延至 5 年 |

### ✅ 明确能做

| 事项 | 说明 |
|---|---|
| 在港合法开户（储蓄功能），如实说明用途 | 合法 |
| 用港卡在港/境外**刷卡消费** | 不占 5 万美元额度，也不受境外提现 10 万元/年限制（那是境内卡的限制） |
| 买 **QDII 基金** | 10 元起，人民币交易，证监会 + 外汇局双审批，**唯一零门槛合法境外投资**。注意限购与场内溢价 |
| 未来资产达标后开**港股通** | 50 万日均资产；转让差价**暂免个税至 2027-12-31** |
| 依法申报境外所得 | 次年 3.1–6.30，可抵免境外已纳税 |

## 六、最容易踩的 5 个坑（实操层）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | 没提前开手机号**国际漫游**，到港收不到验证短信 → 开不了线上户 | 出发前在运营商 App 开通漫游（收短信，非流量） |
| 2 | **地址证明用错**（用身份证地址 / 无章水电单） | 备**信用卡近 3 个月彩色带章账单**（姓名 + 完整地址） |
| 3 | 开户理由填"储蓄/备用"又拿不出佐证 → 被拒 | 填"**投资理财**"并准备**基金/股票持仓截图**（哪怕几百元）+ 资金来源说明 |
| 4 | 花 1000–3000 元找中介"包开户" | 自己用 App 就能开，中介是整治对象 |
| 5 | 开了就放着不动 → 被降级/收费/关闭 | 至少每 6 个月登一次、转一笔小额；**平安数字银行 6 个月不动即暂停网银**（最严） |

### 赴港开卡行动清单

**行前（1–2 周）**
- [ ] 港澳通行证 + 有效签注（G/L 均可），证件有效期 ≥ 6 个月
- [ ] 内地身份证原件
- [ ] **开通手机号国际漫游**（收短信用）
- [ ] 地址证明：信用卡近 3 个月账单（彩色、带章、姓名地址清晰）
- [ ] 投资佐证：券商/支付宝/微信基金持仓截图
- [ ] 资金来源说明（父母资助声明 + 流水）
- [ ] 带 1000–2000 港币激活金
- [ ] 下载 App：BOCHK、HSBC HK、ZA Bank、蚂蚁银行、大象银行

**过关时**
- [ ] 拿好**入境小白条**，立刻拍照存云盘
- [ ] 连香港 WiFi / 买日租流量卡
- [ ] **入境后**再用"移民局 12367"小程序下载出入境记录 PDF（提前下载的无效！）

**在港办理**
- [ ] 优先连 WiFi 用 App 开中银 / 汇丰（人在港、开定位、NFC 读通行证）
- [ ] 兜底：赴居民区网点（上水 / 屯门）walk-in
- [ ] 面谈口径统一：学生 + 父母资助 + 投资理财需求 + 持仓截图
- [ ] **邀请码必须开户时填**，事后无法补填

**离港后**
- [ ] 跟踪卡片/密码函邮寄
- [ ] 设"每 6 个月登一次、转一笔小额"提醒
- [ ] 证件到期换新后第一时间在 App 更新

## 七、最后一句

> **你现在的最大优势是"没有历史包袱"**——没有违规记录、没有未申报的境外所得、没有说不清来源的资金。请保持这个状态。
>
> 在无资产、无收入的阶段去碰跨境投资，**风险远大于收益**。把这几年的时间和那点闲钱，投在**电气工程的专业能力**上（考证、竞赛、实习、硬件动手），回报率大概率高于任何金融产品，而且不承担 3.8% 的摩擦成本——这不是安慰话，是有数据支撑的结论。
>
> **港卡可以开，当它是"提前拿到一张境外账户的门票"；但不要把它当成"赚钱的工具"。**
