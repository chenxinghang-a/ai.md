一、名词速懂（看不懂就点开）

这些名词本质是把《电工学(下)》里的二极管、三极管、门电路、触发器，换成能焊、能画、能编程的实体工具。
🔧 电烙铁 / 焊台
加热到高温的金属头，把锡熔在焊点上固定元件。类比：更精细的"接线工具"。所有元件连成电路全靠它。
🔧 焊锡丝
带助焊剂的细锡丝，受热熔化形成焊点，是连接两个引脚的"导电胶水"。必须买含松香芯的，否则不沾锡。
🔧 松香
助焊剂，帮锡更容易粘上金属、去氧化。没它焊点又黑又虚。
🔧 吸锡器 / 吸锡线
焊错时把多余熔锡吸走的"后悔药"。吸锡器吸不到的细脚锡渣用铜编织吸锡线补。
🔧 虚焊
看似焊上实际没导通、时通时断。类比导线"接触不良"。新手最易犯，导致电路莫名不工作。
🔧 直插元件 / 贴片元件(SMD)
直插=腿长、穿板孔焊，新手首选好拿好焊；贴片=贴在板面无长腿、体积小，是现代板主流，练手后再碰。
📋 面包板
带弹性铜夹的塑料板，元件插上即通、不用焊。类比"临时搭电路的无焊实验板"，初学验证零成本。
📋 洞洞板
打满孔的环氧板，自己焊元件永久固定。面包板的"焊死版"，做能长期用的小作品。
📋 PCB / 原理图
PCB=印刷电路板，铜箔走线替代飞线；原理图=用符号画的电路连接图（就是课本里的电路图），画板前必须先有它。
📋 立创EDA / 嘉立创打样
立创EDA=在线免费画原理图/PCB的"画图Word"；嘉立创=把你的PCB文件做成实物的厂家，每月首单免费打样（10×10cm内，只付邮费）。
📋 绿油 / 有铅无铅喷锡 / 2层4层板
绿油=板面绿色绝缘漆防短路；喷锡=焊盘表面镀锡层，新手选有铅更好焊（熔点低）；2层板简单电路够用，复杂才要4层。
📟 数字万用表 / 示波器
万用表=测电压/电流/电阻/通断的数显仪，排查必备；示波器=把电压随时间画成波形的"慢动作录像"，看信号波形用，新手可先不买。
📟 蜂鸣档 / 二极管档
蜂鸣档=通就"滴滴"响，查虚焊查线最快；二极管档=测二极管/LED好坏（正向通反向不通，正是你学的二极管特性）。
🤖 单片机(MCU) / Arduino UNO R3
MCU=自带CPU的小芯片，跑程序自动控制外设，让电路"智能"起来；Arduino UNO R3=最易上手的"乐高入门套装"，接线简单资料多，新手首选（认准 R3+CH340 版）。
🤖 STM32F103C8T6（蓝Pill）/ 开发板 / 最小系统
蓝Pill=性能更强的32位开发板，便宜，进阶用；开发板=芯片焊好带接口的"带壳成品"开箱即用；最小系统=让芯片能跑的最简电路（电源+晶振+复位），自己画PCB必须会。
🤖 ST-Link / USB-TTL(CH340)
ST-Link=给STM32烧程序的"喂程序U盘线"；CH340 USB-TTL=电脑USB转串口，是电脑和芯片间的"翻译官"，没它连不上。
🤖 GPIO / PWM / 定时器 / 中断 / 串口 / HAL库
GPIO=可配置输入输出的"可编程开关脚"；PWM=用占空比快速开关等效调电压；定时器=内部"闹钟/秒表"精准计时；中断=有急事打断主程序去处理再回来；串口=单片机"发短信"调试通道；HAL库=厂家现成函数库，调函数即用不用啃寄存器。
🧩 杜邦线 / 限流电阻 / LED / 舵机 / L298N / DS18B20 / 红外对管
杜邦线=可插拔彩色软导线；限流电阻=串回路限流防烧 R=(Vcc−Vled)/I；LED=发光二极管(第1章)，不串电阻会烧；舵机=转指定角度的智能马达；L298N=放大弱信号驱动大电机的"放大器"；DS18B20=数字温度传感器；红外对管=遮挡即触发，做避障/循迹。

三、10周学习路线（每周打卡）

第1–2周 练焊接洞洞板+直插件
操作
买烙铁、锡丝、松香、吸锡器、杜邦线、1kΩ/220Ω电阻、红绿LED、9V电池盒。第一周把电阻两脚插洞洞板，烙铁沾松香再吃锡，焊点喂圆润发亮，焊10个电阻+LED（长脚=正极）。第二周练拆焊：吸锡器对准焊点，烙铁加热同时按吸锡器吸走锡拔元件；再焊"电池→电阻→LED→地"回路点亮。
挂钩
LED就是《电工学(下)》第1章半导体二极管——正向导通、反向截止，长脚=阳极；限流电阻 R=(Vcc−Vled)/I 是基操。课本学的二极管特性，现在动手焊亮它。
成果
自己焊亮一盏LED，能熟练拆焊。
易错
虚焊（表面亮内部没粘）——焊点要呈圆锥吃住两脚；温度别太高烫坏LED；手抖买焊接固定夹。
第3周 画第一块PCB立创EDA
操作
百度"立创EDA"网页版注册→新建工程→放1个LED、1个220Ω电阻、2个排针。连线 VCC→电阻→LED→GND。切"PCB"摆元件走线（单面板，线宽0.3mm）。点"下单PCB"→嘉立创下单助手免费打样。
挂钩
画板=布"导线"；给板子供电的思路来自第5章直流稳压电源(7805/LM317)，先做简单电池供电版，进阶再画稳压电路。
成果
几天后收到绿色小板，自己焊元件接电池点亮。
易错
封装选错（LED脚距不对焊不进）；走线别交叉，单面板尽量不跳线。
第4周 Arduino点灯
操作
装 Arduino IDE（官网免费）。买Arduino UNO+数据线。打开 示例→01.Basics→Blink，选对板子(COM口)，点"上传"。板载13脚LED会闪。
挂钩
digitalWrite(13,HIGH/LOW) 输出的就是第7章门电路的高低电平(0/1逻辑)；写代码=控制这个电平，和数电真值表一脉相承。
成果
板载灯闪烁，理解"写程序控制硬件"。
易错
驱动没装→换数据线/装CH340驱动；COM口选错。
第5周 按键+串口
操作
按键一端接D2、另一端接地，D2再接10kΩ上拉到5V。程序 digitalRead(D2)，按下为LOW。Serial.begin(9600)+Serial.println("按下")，开"串口监视器"看打印。按键会抖——代码里"检测到按下后延时20ms再判一次"消抖。
挂钩
按键=机械开关；串口打印的数字逻辑对应第7章组合逻辑；上拉电阻保证悬空时是确定高电平（不是课本里的"悬空易干扰"那套）。
成果
按一下键，电脑打印一行字。
易错
忘了上拉电阻电平悬空乱跳；不消抖会连发多次。
第6周 定时器/中断
操作
用 millis() 做不阻塞延时（取代delay，灯闪同时还能干别的）。学外部中断 attachInterrupt(0,函数名,RISING)——按键接D2，每按一次中断函数让计数+1，串口打印次数。
挂钩
定时器/计数器直接对应第8章时序逻辑(触发器/计数器)和第9章555定时器——课本里"数脉冲"现在真在数了；中断=随时响应外部事件。
成果
按键计数精准不漏按。
易错
中断函数里别用delay、别做复杂运算。
第7周 PWM调光
操作
analogWrite(9, 0~255) 输出PWM。接LED+电阻，亮度0→255→0看呼吸灯。加舵机(<Servo.h>库)转不同角度；或蜂鸣器调音调。
挂钩
PWM就是第9章方波/脉冲信号，占空比越大等效电压越高→LED越亮/电机越快，用占空比"假装"调模拟量。
成果
呼吸灯+舵机转动。
易错
不是所有脚支持PWM，UNO上带"~"号的才行。
第8周 转STM32（F103C8T6）
操作
买"STM32F103C8T6最小系统板"+"ST-Link下载器"。装STM32CubeMX+Keil(或VS Code+PlatformIO)。CubeMX点几下配置PA0输出/串口/定时器PWM，生成HAL代码。写HAL_GPIO_TogglePin点灯，重做按键/串口/PWM。ST-Link连好点"下载"。
挂钩
GPIO/定时器/PWM原理同前，只是芯片换成更专业的Cortex-M3，用CubeMX图形配置代替手写寄存器。第7/8章知识直接复用。
成果
STM32点灯+串口打印。
易错
BOOT0跳线位置不对下不进去；ST-Link接线(VCC/SWCLK/SWDIO/GND)别接反。
第9–10周 小项目
方案A
温控风扇：DS18B20测温(单总线库)→温度高就analogWrite调大风扇PWM转速，串口显示温度。
方案B
循迹小车雏形：2个红外传感器接STM32，读到黑线就控制左右轮(PWM调速减速电机)修正方向。
挂钩
模拟传感器→第3章运放信号调理→ADC采集，对应第11章AD/DA；把数电/模电全串成一个系统，写进暑假作业报告。
易错
先分模块调通再组装，别一口气焊完才发现某块不工作。
