✅ 验证清单（都装完后逐项过）

  1. Python：Win+R 输入 cmd → python --version 应显示 3.12.8
  2. Arduino：打开 Arduino IDE → 文件→示例→01.Basics→Blink → 选板子(UNO) → 编译（✔）不报错
  3. CubeIDE：开始菜单开 STM32CubeIDE → File→New→STM32 Project → 选 STM32F103C8Tx → 生成代码 → 编译（锤子）通过
  4. ST-Link：套件 ST-Link 插 USB → 设备管理器"通用串行总线设备"出现 STM32 STLink 且无黄叹号
  5. CH340：插 USB-TTL 模块 → 设备管理器"端口"出现 USB-SERIAL CH340 (COMx)

📌 排错

  • 设备管理器有黄叹号/未知设备 → 重跑 install_drivers.bat（管理员）
  • ST-Link 不识别 → 从 CubeIDE 安装目录找 ST-Link 驱动，或 ST 官网下 en.stsw-link009.zip 双击 dpinst_amd64.exe
  • Arduino 编译报缺板包 → 开发板管理器搜 "Arduino AVR" 安装
  • python 不是 3.12.8 → 重启终端；仍不对就把 C:\Users\cxx\.workbuddy\binaries\python\versions\3.12.8 置顶 PATH
