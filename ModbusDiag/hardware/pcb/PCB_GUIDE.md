# ModbusDiag PCB设计指南

## 板层叠
- **层数**: 2层 (FR4, 1.6mm厚)
- **铜厚**: 1oz (顶层/底层)
- **表面处理**: HASL (喷锡)
- **最小线宽/线距**: 6mil/6mil (0.15mm)
- **最小过孔**: 0.3mm孔径/0.45mm外径

## 板子尺寸: 100mm × 65mm

### 关键布局规则

1. **ESP32-S3**
   - 晶振(Y1)必须尽可能靠近芯片 (距XTAL_P/N引脚 < 10mm)
   - 晶振走线两侧包地隔离
   - Flash/PSRAM要靠近芯片
   - VDD3P3退耦电容(< 2mm距离)

2. **电源**
   - TP4056靠近USB-C输入
   - 大电流路径走粗线(≥0.5mm)
   - 电源地要星形连接，避免数字地干扰
   - AMS1117需散热焊盘，底部过孔散热

3. **RS485**
   - MAX13487靠近接线端子
   - A/B走线差分对，线宽0.25mm，间距0.25mm
   - TVS管紧靠接线端子
   - 隔离地(可选)：可割地隔离数字和RS485地

4. **TFT屏幕**
   - SPI走线尽量短
   - SCK/MOSI之间不要平行太长（防止串扰）
   - BL背光PWM走线远离RF天线区域

5. **天线（WiFi/BLE）**
   - ESP32-S3天线区域(PCB末端)不可铺铜
   - 天线匹配电路靠近天线
   - 天线区域底部不可有走线

## 走线宽度参考

| 网络 | 电流 | 线宽 |
|------|------|------|
| 电池+/5V | 1A | 1.0mm |
| 3.3V | 500mA | 0.5mm |
| USB信号 | - | 0.25mm差分 |
| RS485 A/B | - | 0.25mm差分 |
| SPI信号 | - | 0.2mm |
| I2C信号 | - | 0.2mm |
| GPIO/按键 | - | 0.2mm |

## 建议布局流程

1. 放置所有元件在板子轮廓内
2. 先走电源主干（粗线供电）
3. ESP32-S3核心电路（晶振、退耦电容优先）
4. RS485差分对
5. SPI显示总线
6. I2C触摸总线
7. 按键、指示灯、蜂鸣器
8. 铺铜（GND层），添加过孔
9. DRC检查
10. 导出Gerber
