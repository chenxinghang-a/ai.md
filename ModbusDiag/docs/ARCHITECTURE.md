## GPIO分配表

| GPIO | 功能 | 连接目标 | 备注 |
|------|------|---------|------|
| GPIO1 | USB_D+ | USB | USB-OTG，连接CP2102 |
| GPIO2 | U0TXD | USB转串口 | 调试串口 |
| GPIO3 | SPI2_CS | TFT屏幕 | ILI9488片选 |
| GPIO4 | TFT_DC | TFT屏幕 | 数据/命令 |
| GPIO6 | SPI2_CLK | TFT/MAX13487 | SPI时钟 |
| GPIO7 | SPI2_MOSI | TFT/MAX13487 | SPI主出从入 |
| GPIO8 | SPI2_MISO | TFT(可选) | SPI主入从出 |
| GPIO9 | TFT_RST | TFT屏幕 | 复位 |
| GPIO10 | TFT_BL | TFT背光 | PWM控制 |
| GPIO11 | TFT_CS | TFT屏幕 | 备用片选 |
| GPIO14 | I2C_SDA | FT6236触摸 | 触摸屏I2C数据 |
| GPIO15 | I2C_SCL | FT6236触摸 | 触摸屏I2C时钟 |
| GPIO16 | RS485_RE | MAX13487 | 接收使能(低电平有效) |
| GPIO17 | RS485_DE | MAX13487 | 发送使能(高电平有效) |
| GPIO18 | RS485_RX | MAX13487 | UART接收(连MAX13487 RO) |
| GPIO19 | RS485_TX | MAX13487 | UART发送(连MAX13487 DI) |
| GPIO20 | BAT_ADC | 电池分压 | ADC检测电池电压 |
| GPIO21 | LED_R | RGB_LED | 红色指示灯 |
| GPIO22 | LED_G | RGB_LED | 绿色指示灯 |
| GPIO23 | LED_B | RGB_LED | 蓝色指示灯 |
| GPIO24 | BUZZER | 蜂鸣器 | PWM驱动 |
| GPIO25 | BTN_UP | 按键 | 上 |
| GPIO26 | BTN_DOWN | 按键 | 下 |
| GPIO27 | BTN_OK | 按键 | 确认 |
| GPIO28 | BTN_BACK | 按键 | 返回 |
| GPIO42 | USB_D- | USB | USB-OTG |
| GPIO43 | U0TXD | CP2102 | 调试串口TX |
| GPIO44 | U0RXD | CP2102 | 调试串口RX |
| GPIO45 | BOOT_CFG | 上拉 | 启动配置 |
| GPIO46 | NC | 悬空 | 或作为扩展 |

## 电源树

```
锂电池 (3.7V 18650)
    │
    ├── TP4056 充电管理 ─── USB 5V输入
    │
    └── MT3608 升压至5V
        │
        └── AMS1117-3.3 ─── 3.3V 供给
            ├── ESP32-S3 (最大500mA)
            ├── MAX13487 (最大5mA)
            ├── TFT屏幕 (最大200mA)
            ├── FT6236触摸 (最大10mA)
            └── 其他外设 (最大50mA)
```
